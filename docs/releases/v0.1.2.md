# v0.1.2 - 收听增益与语音优先界面

本版完善游戏连麦的收听控制、频道实时文字和桌面设置，继续属于 0.x 预览版本。

## 变化

- 全局收听与单人收听使用 dB 调整，两层增益叠加。全局默认 +6 dB，单人默认 0 dB，范围均为 -20 至 +18 dB，保留独立静音；全局调整不重开音频设备，混音增加帧峰值限幅。
- 频道与成员作为主要工作区，实时文字放在底部可折叠、可拖高面板，支持复制、HTTP(S) 链接和固定尺寸发送按钮。
- 文字仅属于本次频道会话，不持久化、不补历史。成功切频道、离服和重连成功清空旧记录，过滤迟到旧频道消息；显示缓存限制为 500 条及 512 KiB 文本内容。
- 设置采用草稿，点击“应用”并确认核心配置完成后保存；取消或退出不保存未应用修改。通话工具栏和单人音量保持即时生效。
- 默认 800×900 竖向窗口，最小 760×600，修复缩窄时主区、输入框与底栏变形；设置内容自适应宽度。macOS 标题栏与暗色界面一体，保留原生窗口操作。
- 增加钥匙串操作边界的内存诊断，不记录密码或条目标识；macOS 打包支持指定证书签名，未指定时使用 ad-hoc 签名并校验完整性。
- 新增独立 macOS Actions，分别提供 Apple Silicon 与 Intel ZIP，沿用 Windows 的分支 -dev、标签版本和提交 SHA 命名规则。

## 升级

沿用 RN05，不修改网络协议，无需配套升级服务器。桌面与内置 core 应作为同一包升级。新版默认收听增益 +6 dB 比旧版更响，可通过底栏或设置调整；麦克风增益与提示音保持独立。

## 验证与限制

Go internal 竞态测试、Rust 桌面测试和 macOS release 构建通过；本机已验证收听控制、设置、默认与最小窗口以及打包/解压后的签名完整性。产品流程审查与验收边界见 docs/product.md、docs/verification.md。

macOS 旧密码条目连续两次授权仍是已知问题：系统日志确认旧条目与新 ad-hoc 二进制存在 ACL/partition 身份不匹配。稳定证书配置和跨版本授权验证延期；当前包未使用 Developer ID，也未经过 Apple 公证。

Windows 与 macOS 双架构远端构建需以该标签的 Actions 结果为准；Windows 多人听感、游戏性能、长时语音与 Intel Mac 运行仍待验收。工作流 artifacts 保留 14 天，本标签不自动创建持久 GitHub Release 下载资产。
