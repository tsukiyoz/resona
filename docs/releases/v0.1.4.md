# v0.1.4 - 可配置音频处理与桌面设置

本版完善独立的 AEC、ANS、AGC 配置与桌面体验，继续属于 0.x 预览版本。

## 变化

- 输入侧提供回声消除与背景噪声抑制，接收侧对每位成员独立进行自动增益，再应用个人音量与混音。支持关闭、SpeexDSP，以及随包提供的 WebRTC AEC3、NS、AGC2 实现。
- 设置选项及说明从 core 能力接口获取。配置点击确认后异步应用，在音频帧边界替换处理实例；取消保留原配置。新安装默认开启 SpeexDSP 收听自动增益，保留已有用户明确保存的选择。
- 设置拆分设备与声音栏目，新增关于、诊断与 core 探测入口，改善导航对齐、滚动区域及处理选项的说明提示。
- 支持跟随系统、浅色、深色主题。应用内标志及支持动态更新的原生图标随主题切换，无法动态切换的打包图标默认使用白底黑线版本。
- 服务器记录认证后的成员连接、断开、来源 IP、名称和连接时长，不增加逐语音包日志。
- 新增固定 gofumpt 版本的 `make format`，并以独立提交统一 Go 代码格式。

## 升级

不修改 Noise UDP 网络协议。桌面、内置 core 和 WebRTC 原生库应作为完整应用包一起升级；服务器升级可获得新增连接日志。

## 验证与限制

功能合并前完整 Go 内部包竞态检查、40 项桌面 Rust 测试及 WebRTC 原生库测试通过。格式化后全仓 Go 测试及构建清理边界检查通过。本机 macOS debug 应用打包与设置、主题交互已验证。

Windows 原生图标及任务栏行为、多人成员语音与游戏负载下的长期表现仍需实机验收。固定到任务栏的快捷方式可能使用系统缓存的静态图标。远端 Windows 与 macOS 双架构打包结果以本标签 Actions 为准。

macOS CI 使用现有 Apple Development 签名，未进行 Apple 公证。Actions artifacts 保留 14 天，本次标签不自动创建持久 GitHub Release 资产。
