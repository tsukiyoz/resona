# v0.2.0 - Rust 客户端与服务器本地账号

本版整合 v0.1.5 以来的客户端迁移、服务器管理、近期聊天历史与账号体系，
继续属于 0.x 实验预览版本。客户端和服务器必须配套升级。

## 变化

- Desktop 使用进程内 Rust 客户端，迁移连接、偏好、设备、Opus 与音频处理链，
  不再打包 Go Core 或使用客户端 IPC。减少无状态变化时的重绘，并修复 Windows
  标题栏主题跟随。
- ANS 可选择 SpeexDSP 或 RNNoise，提供算法说明；保留独立 AEC、ANS、AGC 配置。
- 内置 NATS JetStream 保存有界频道历史，支持连接及切频道时补齐近期消息。
  管理资源使用 KV 持久化并推送变化；频道顺序持久化，桌面支持拖动排序。
- 服务器提供基于 Casbin 的管理授权、HTTP 管理接口与内置后台，可管理频道、
  成员角色、封禁、服务器设置和聊天保留上限。
- 设备默认以游客连接；设置中的用户页支持当前服务器的注册、密码或 Token 登录、
  中文昵称修改、改密与退出。账号拥有稳定 UID，用户名创建后不可修改。
  同一账号的新语音登录会替换旧连接，后台登录不挤掉语音连接。
- 账号使用 SQLite WAL 存储，密码以独立随机盐和 Argon2id 散列保存，Token 仅存摘要。
  密码要求为 8–256 UTF-8 字节；账号凭据不进入普通配置、日志和诊断导出。
- 简化登录与注册表单，明确校验失败原因，调整声音页间距与窄窗口布局。
  聊天发送键左侧增加本地 emoji 选择器，可在光标处插入或替换选区，不自动发送。

## 升级与身份重置

升级前停止服务器，并完整备份 data/access 及自定义的聊天、账号存储目录，
包含 SQLite 数据库与 WAL 和 JetStream 数据。保留现有私有连接配置。

本次实验性身份升级会一次性清除旧设备绑定的 owner/admin 权限、旧管理凭据、
认领状态和封禁；所有旧设备以游客进入，不自动继承账号。频道、服务器设置与
聊天历史保留。请在新版客户端注册账号，再使用服务器离线生成的新认领码取得
owner；旧后台 Token 不是新账号登录凭据。详见 docs/server.md 和 ADR-0035。

本版包含原生控制消息与资源语义变化，不能混用 v0.1.5 客户端和新版服务器。
传输仍仅为 Noise UDP，语音仍使用 Opus。请完整替换应用包，保留用户配置目录。
已经执行过身份升级的预发数据不会再次重置权限。不要通过直接降级二进制回滚数据。

## 验证与限制

身份与桌面改动已通过 Go internal 测试、相关竞态检查、make lint、Rust 客户端
46 项单测及 23 项 Go/Rust 回环互通、桌面 55 项测试。Clippy 沿用已记录的三类
既有风格告警允许项，其余按 -D warnings 检查。验证记录见 docs/verification.md。

macOS 签名 release 实窗已验证注册、中文昵称、emoji 传输与历史、表情面板的
选区替换、光标插入、Esc 与频道切换行为。预发服务器已完成数据备份和健康检查。
Windows 实窗、原生 IME、深色表情面板与游戏负载仍需验收；不据此宣称新的性能结果。

标签构建成功后才发布 Windows x64、macOS arm64/x64 完整应用包及签名更新清单。
当前应用包为便携版，更新检查引导用户下载替换。macOS 沿用 Apple Development
签名，尚未进行 Developer ID 公证。最终跨平台构建结果以本标签 Actions 为准。
