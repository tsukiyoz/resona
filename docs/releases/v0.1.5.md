# v0.1.5 - 连接可靠性与手动更新

本版完善连接、资源同步、配置保护和便携版更新，继续属于 0.x 预览版本。

## 变化

- 连接与资源同步分别显示状态。临时连接错误和资源请求支持三次短重试；失败后提供明确重试与退出入口。已有缓存时前台恢复静默同步，避免状态文字闪烁。
- 聊天消息的复制按钮仅在悬停该行时显示，保留按钮槽位，避免正文跳动。
- 本地偏好及书签加入格式版本、旧配置迁移备份和异常写入保护，损坏、未知或未来格式不被静默覆盖。
- 更新入口仅保留在“设置 → 关于”。用户主动检查后，验证签名清单并打开对应版本的 GitHub Release 页面，自行下载完整应用包替换。
- 当前 Windows ZIP 与 macOS .app ZIP 明确标记为 portable；不在应用内下载、安装或退出更新。安装包及安装器自动升级仍待实现。
- 更新检查最长等待 10 秒，失败显示具体网络、HTTP 或清单原因，主动取消单独显示；不增加启动联网、后台轮询或诊断写盘。
- tag 发布流程产出 Windows x64、macOS arm64/x64 三个平台包及 Ed25519 签名的 manifest.json；所有包成功后才公开 Release，已有发布不可覆盖。
- 统一 Go 静态检查入口为 make lint。

## 升级

未修改 Noise UDP 网络协议。请将 Desktop、Core 和随包原生库作为完整应用包一起替换，保留现有用户配置目录。已有配置首次保存前备份；不保证未来版本配置可降级读取。

本版首次发布更新清单。旧构建若未内置更新公钥、未带发行类型元数据或使用旧清单格式，需要先手动下载本版。当前版本检查同版本发布后显示已是最新，不会提示重复更新。

## 验证与限制

Go 内部包、更新发布工具测试、更新及 IPC 竞态检查、make lint 和 47 项桌面测试通过；本机 macOS 发布构建及签名严格验证通过。关于页入口、手动检查和明确失败原因已完成本机浅色实窗验证；发布后的公共清单及多平台构建结果以本标签 Actions 为准。

Windows 多人长时间使用、游戏负载、深色及最小窗口的完整实机验收仍需继续。没有因本版改动而宣称新的性能测量结果。

macOS CI 使用现有 Apple Development 签名，未进行 Apple 公证；这不是 Developer ID 公共发行签名。Actions artifacts 保留 14 天，GitHub Release 的应用包及更新清单为正式下载入口。
