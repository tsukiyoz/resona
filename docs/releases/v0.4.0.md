# v0.4.0 - 地址与密码连接、私有认证存储

## 功能与改进

- 有连接密码的服务器支持只填地址和密码。客户端通过 OPAQUE PAKE 认证发现的
  Noise 公钥，认证完成前不发送身份、昵称或账号 Token；手动填写的公钥仍严格校验。
  无密码公开服务器继续要求包含可信公钥的邀请信息。
- Owner 可在管理后台修改或随机重置服务器连接密码，已在线语音连接不中断。
  认证记录保存在私有 JetStream KV，不保存明文密码、不写入日志或普通资源推送；
  记录缺失或损坏时拒绝启动，避免意外变为公开服务器。
- 新增离线 `password set --password-stdin` 和 `password reset` 子命令。
  随机密码仅在确认保存成功后展示一次，遗失后需要重新重置。
- Owner 认领码保存摘要和到期时间，24 小时有效，认领成功立即消费；显式操作后
  展示明文，不默认另存独立文件。
- 服务端复用发送缓冲和争用等待计时器，减少热路径分配；保留直接 socket 写入模型。
  每位收听者语音待发队列默认 16 槽，可通过 `serve --voice-queue-slots` 配置。
  连接日志区分初始名称与后续登录身份。

## 升级与不兼容变化

协议从 RN06 升为 **RN07**，旧客户端不能连接新版服务器，新客户端也不能连接旧版。
请配套升级客户端和服务端，完整替换应用包，并保留客户端配置、身份及系统凭据。
原有语音包、编解码和路由方式不变。

服务端不再接受 `serve --password-file`、`RESONA_SERVER_PASSWORD` 或
`RESONA_SERVER_PASSWORD_FILE`。已有密码文件部署须先备份持久数据，并在停服后使用
新版 `password set --access-dir <目录> --password-stdin` 显式导入原密码，随后移除旧
启动参数和环境配置。部署脚本会拒绝未经处理的旧配置。私有 KV 应随 access 数据
一起备份；降级时恢复与旧版本对应的数据快照，不直接复用新版状态。
