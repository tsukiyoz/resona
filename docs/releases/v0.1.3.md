# v0.1.3 - 频道工作区与 macOS CI 签名

本版完善频道工作区的显示归属，接入 macOS 构建证书签名，继续属于 0.x 预览版本。

## 变化

- 频道文字从当前展示服务器内已加入的有效频道派生。未连接、未加入频道、重连等待或查看其他服务器时隐藏整块文字面板并释放空间；隐藏输入不接受迟到发送，拖动随面板隐藏停止。
- 切频道等待保留原频道文字但禁止发送；成功切换清空，失败且仍在原频道时保留。重连期间仅暂存文字，恢复后清空，不补历史或自动重发。
- 频道区始终展开、自适应宽度，移除频道栏收起按钮和偏好。保留服务器栏收起、底部文字折叠与成员详情。旧偏好中的频道收起值忽略，其他设置保留。
- macOS 主分支/标签构建及主分支手动构建从 Actions Secrets 导入指定证书，在临时钥匙串内签名并清理。缺失或无效证书使可信构建失败；PR 与非主分支手动构建继续使用 ad-hoc 签名且不读取签名 Secrets。

## 升级

不修改 Noise UDP 网络协议，无需配套升级服务器。桌面与内置 core 仍作为同一包升级。

本机已验证由相同 Apple Development 身份创建的密码条目在进程重启及另一构建中正常读取。旧 ad-hoc 条目可能仍存在 ACL/partition 身份不匹配，需要重新保存密码；不自动放宽钥匙串权限，也不保证任意旧条目无提示迁移。

## 验证与限制

32 项 Rust 桌面测试、macOS release 签名打包、PKCS#12 独立临时钥匙串导入及 workflow actionlint 校验通过。实窗确认未连接时不显示文字面板，且频道收起按钮已移除。Windows 实机、Intel Mac 运行和多人语音体验未在本轮重复验收。

当前 CI 配置使用 Apple Development 证书，不是 Developer ID 发布签名，也未经过 Apple 公证。远端 Windows/macOS 双架构打包以本标签 Actions 结果为准；证书 Secrets 已配置不代表远端签名构建已通过。Artifacts 保留 14 天，不自动创建持久 GitHub Release 资产。
