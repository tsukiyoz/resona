# v0.1.1 - 自动重连与内存诊断

本版改善连接恢复和语音排查，继续属于 0.x 预览版本。

## 变化

- 成功连接后的意外断线自动退避重试，支持取消、切换服务器和退出；首次连接失败、明确认证拒绝不循环重试。
- 重连恢复持久身份、原频道及语音设置，麦克风保持静音，按键发言需重新按下；原频道不可用时留在当前频道并提示。不自动重发聊天或管理命令。
- 默认以预分配内存环保存最多 512 条、最近 15 分钟的结构化诊断事件。容量满覆盖旧记录，竞争时丢弃计数，音频热路径仅累计计数；没有额外闲置日志计时器或周期写盘。
- 语音设置新增“导出诊断”，主动点击后异步写本地 JSON 并定位文件。包含版本、连接与设备事件、音频路由及解码等统计，不自动上传；退出或崩溃会丢失未导出的内存记录。

## 升级

沿用 RN05，兼容 v0.1.0 原生服务端；本次客户端更新无需配套升级服务器。地址、公钥、UDP 端口、频道和权限数据不变。传输仍为逐跳加密。

## 验证与限制

Go 竞态测试、Rust 桌面测试及 macOS release 构建通过。临时真实服务器验证断线重连、取消与身份保持，macOS 实际窗口验证静音恢复和诊断导出。

Windows 包由此 tag 的 Actions 构建验证，发布时尚不能声称 Windows 游戏负载、休眠恢复、网络/蓝牙设备切换及多人长时间语音全部验收。内存事件微基准不等于游戏 1% low 测量。逐发送者诊断采用时间段汇总，不能据此直接推算公网丢包率或端到端延迟。

工作流 artifacts 保留 14 天，本 tag 本身不会创建持久 GitHub Release 下载资产。
