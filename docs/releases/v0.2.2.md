# v0.2.2 - 语音恢复与按需聊天历史

## 修复与体验

- 播放按声卡缓冲余量补帧，避免线程晚醒后延迟累积；语音停顿后可重新建立
  播放窗口，避免结束标记丢失导致恢复说话后仍被当作迟到帧丢弃。
- 同连接内切频道、游客注册或登录保留音频设备及发送处理链，只切换路由并
  丢弃旧范围音频。修复资源刷新与设备打开竞争导致收发失声的问题。
- 注册沿用本机设备、3A、音量和发言偏好，不上传为账号配置；账号昵称同步
  服务器。游客角色展示统一，设置中的用户栏目更名为“身份”。
- 消息改为整行右键复制，移除悬停复制按钮。
- 进入频道先加载最新最多 20 条消息，向上翻页再加载最多 20 条，单页最多
  48 KiB。实时接收独立进行，加载旧页保持阅读位置，失败可手动重试。
  本地浏览仍受 500 条 / 512 KiB 限制，避免自动拉取全部保留历史。

## 升级

完整替换应用包并保留用户配置。聊天分页扩展了 Protobuf 控制消息，Noise UDP
包头和加密格式不变；请配套升级客户端与服务器，旧服务器不提供旧页接口。
服务器升级前备份完整 data/access 和自定义数据目录。已有聊天 Stream 会启用
内部 direct read，不重置账号、频道、消息或自定义留存限制。

## 验证与限制

Go internal 全量、server/nativewire 竞态检查和 make lint 通过；Rust 客户端
51 项单元、桌面 56 项单元及 Go 1.26.0 下串行 25 项跨语言互通通过。
原生音频回调 ASan/UBSan 通过。客户端严格 Clippy 通过，桌面放行已记录的
三类既有警告后通过；产品流程复审通过。

既有 ACK 丢失语音测试在并行重任务期间曾未达到接收门槛，完整串行复测通过，
未放宽阈值。维护者已确认前一轮 Windows 卡顿改善；本轮 macOS 签名开发包
与预发服务器已交付，反复切频道、在线注册和游戏负载仍需 Windows 实机验收。

标签 Actions 成功后才发布 Windows、macOS arm64/x64 包及签名更新清单。
macOS 使用 Apple Development 签名，未进行 Developer ID 公证；便携包需手动
下载替换。完整本地验证与预发部署证据见 [验证记录](../verification.md)。
