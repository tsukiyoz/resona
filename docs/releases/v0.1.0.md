# v0.1.0 — 首个纯原生版本

Resona 现在仅使用自有 Noise UDP 协议、Protobuf 控制消息与 Opus 语音，GPUI 为唯一桌面界面。此版本仍属于 0.x 预览，不承诺稳定协议或 SDK。

## 变化

- 移除旧协议适配、备用传输、相关依赖与历史对比文档。
- 资源按关注范围 List+Watch；前台实时更新，后台合并状态，恢复前台一次同步，并有五分钟兜底。语音和必要会话状态持续处理。
- 原生成员加入、离开通知；初始同步、本人切频道和订阅范围变化不会制造提示。
- 原生服务器表单和详情精简；不支持的旧书签可管理，在读取凭据及联网前拒绝连接。
- 聊天输入框支持拖动调高、多行滚动，固定尺寸透明发送箭头置于框内右下角，悬停显示细边框。
- Go 运行日志统一使用 slog，保留独立的 IPC 输出通道。

## 升级

握手标识由 RN04 改为 RN05。客户端与服务端必须配套升级；v0.0.3 不能与本版互连。服务器继续使用原有私钥、权限及频道目录，更新前备份完整数据；地址、公钥和 UDP 端口无需变更。

旧书签不会自动转换为原生服务器。填写原生服务器地址与可信公钥，或删除不再使用的书签。

## 验证与限制

Go 全包竞态回归、Rust 桌面测试和 macOS release 构建通过。已验证实际输入框操作以及公网 RN05 握手、身份登录和资源订阅。Windows 打包由 tag 对应 Actions 验证，构建成功不等于游戏场景实测。

自动重连、管理员委派/踢人/封禁、完整拥塞适应尚未实现；Windows 多人长时间听测、游戏焦点 PTT、设备热插拔和全进程 CPU/GPU 验收仍待完成。传输为逐跳加密，服务器可见明文，不是端到端加密。
