# v0.2.1 - 跨平台构建修复

本版包含 v0.2.0 的全部功能，并修复其跨平台构建失败。原 v0.2.0 标签保持不变，
不覆盖旧标签或发布资产。完整功能介绍见 [v0.2.0](v0.2.0.md)。

## 修复

- 账号 SQLite 数据库使用无 authority 的 file URI，避免 Windows 盘符被当作主机名，
  导致数据库无法打开。Windows 测试不再用 POSIX mode 位判断文件权限。
- 合并密码校验的嵌套条件，通过 Rust 客户端严格 Clippy 检查，校验规则保持不变。
- 删除 Go 参考客户端重连拨号后的冗余信号清理，保留拨号前锁内的合并处理。
  用虚拟时间及通道同步替换依赖机器调度的短时间窗口测试，覆盖定时器与立即
  重试竞速、拨号期间拒绝重复请求和下一轮退避，并兼容项目使用的 Go 1.26。

## 升级

相对于 v0.2.0 没有新增协议或数据格式变化。请完整替换应用包，保留用户配置。
从 v0.1.5 或更早版本升级时，客户端和服务器必须配套更新，并先完整备份服务器
data/access 及自定义存储目录。账号体系升级会一次性取消旧设备管理权限，需注册
服务器本地账号并重新认领 owner；已升级过的预发数据不会重复重置。详细步骤见
[v0.2.0 升级说明](v0.2.0.md#升级与身份重置)和 docs/server.md。

## 验证与限制

修复提交 2ee698f 的 Windows 构建、macOS arm64/x64 构建，以及 Linux、Windows、
macOS 的 Rust 客户端检查均已通过。Go 1.26 internal 全量与两项定向 race 测试
（100 次）、accounts/client 完整 race、make lint 和客户端严格 Clippy 已通过。

本标签的发布包和签名更新清单仍由标签 Actions 构建，全部平台包成功后才公开
Release。Windows 实机多人长听、游戏负载、原生 IME 等验收范围没有扩大。
macOS 沿用 Apple Development 签名，未进行 Developer ID 公证；应用包为便携版，
检查更新后需手动下载替换。
