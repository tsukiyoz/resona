# v0.5.0 - 简化管理身份与频道权限

## 功能与改进

- 管理身份收敛为唯一 Owner、管理员和普通用户。Owner 在后台直接为注册账号
  授予或撤销管理员角色；移除管理员令牌发行、兑换、撤销及手动 Token 登录入口。
  日常账号登录仅使用账号密码，应用内部的自动续登保留。
- 新增管理员频道。Owner/admin 可主动进入；已在目标频道内的管理员可以拖拽
  普通用户或游客临时加入，离开、断线或切换账号后临时准入失效。
- 客户端支持分级踢出：管理员可踢普通用户或游客，Owner 可踢管理员；Owner
  不可被踢出或封禁。仅 Owner 可管理封禁。踢出后不自动重连，允许用户手动连接。
- 默认频道始终普通；权限收紧或管理员被撤权后，失去准入的成员返回默认频道，
  保持麦克风和收听意图，不重新打开音频设备。
- 连接失败后允许编辑或删除服务器书签；添加/编辑表单直接使用地址与密码，
  密码继续由系统凭据存储保管，不写入普通配置或日志。
- 服务器栏和右侧详情栏支持拖动吸附收纳；提示音设置补充“戳一下”试听。
- 操作通知使用紧凑、中性的浮层，长错误可滚动查看；管理员频道使用细线盾牌，
  修复原权限图标资源缺失导致的空白。修正后台用户表格分隔线对齐。

## 升级与行为变化

请配套升级客户端和服务端。Noise UDP 的 RN07 标识与语音包格式不变，但新增了
频道访问字段、成员管理命令和能力声明，并收紧了权限规则。旧版界面无法完整呈现
新权限能力，不建议混用版本。

已有账号、Owner/admin 角色、账号续登、服务器密码、频道和聊天数据保留。
原后台管理 Token 及管理员令牌不再接受，使用相应账号密码登录后台。
Owner 的一次性初始化认领码继续保留。升级前备份持久数据；回滚时使用对应备份，
不要依赖旧版本解析并重新保存新版权限数据。
