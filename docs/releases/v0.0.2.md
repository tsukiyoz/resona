# v0.0.2

This early release adds an experimental independent Resona server and native
client transports. Existing TS3 bookmarks continue to use the TS3 adapter.

- Add `cmd/resona-server` with static channels, optional shared password,
  membership, channel chat, voice-state changes and compressed Opus relay.
- Use Noise NK over UDP as the default native server transport, with pinned
  X25519 server identity, authenticated packets, replay rejection and bounded
  reliable control delivery. QUIC/TLS remains an explicit comparison transport.
- Add independent protocol and trust fields to desktop bookmarks. Trust or
  destination changes invalidate previously saved server credentials.
- Add a non-root Docker image and local Compose setup, publishing loopback UDP
  by default and persisting the server identity in a named volume.
- Add reproducible transport and isolated-server GC diagnostics, including
  allocation profiles and a 30-minute 64-client workload report.

## Validation and limits

Go unit/integration/race checks, native macOS desktop checks, Docker client
connectivity and persistent identity checks are recorded in
[verification.md](../verification.md). Local desktop Noise connectivity was also
tested by the user. Windows packaging is built by the main-branch workflow;
Windows native-protocol runtime acceptance remains separate.

The native protocol is experimental and requires matching client/server builds.
It has no automatic rekey or adaptive voice congestion control, and has not
received an independent security audit. This is not an internet-production or
TeamSpeak feature-parity claim. Server setup: [server.md](../server.md).

No production GC tuning or pooling optimization is included. The long test found
rare GC pauses with a worst histogram upper bound of 14.68 ms, a forwarding
maximum of 218.96 ms and 0.0418% missing deliveries to stable members. Their causes
remain under investigation; see [server-gc.md](../server-gc.md). Successful test
completion does not constitute a maximum-latency or zero-loss guarantee.
