# v0.3.0 - 偏好重置、戳一下与服务端命令整理

## 功能与改进

- 设置 → 诊断 → 本地配置增加“重置偏好设置”。确认后恢复默认草稿，点击“应用”
  才生效；保留服务器书签、身份、登录凭据和侧栏布局，不改变当前麦克风及收听静音。
- 右键其他在线用户可“戳一下”，支持跨频道。接收方显示可关闭提醒，声音遵循提示音
  和收听开关；后台保留提醒，不抢焦点、不增加空闲轮询。服务端按发送者和接收者限频，
  提醒不写入聊天历史，不离线补发，成功表示已进入控制队列而非对方已阅读。
- 聊天昵称和时间更紧凑，昵称后增加冒号；频道列表末尾空白处可右键创建频道。
- 统一桌面主题、连接呈现与共享组件，增加独立的调试组件预览；后台查询不再阻塞
  无关操作，异步回执严格核对会话、频道和操作归属。
- 服务端改为显式 Cobra 子命令，根命令不再隐式启动服务器。
- Windows/macOS 打包缓存 Rust 与原生依赖，保留冷缓存构建能力，不承诺固定加速比例。

## 升级与不兼容变化

这是需要配套升级客户端和服务端的协议预览版本。戳一下新增 Poke/Poked 控制消息、
服务端能力字段及参与客户端身份签名的 Hello 接收能力字段。新客户端连接旧服务端
可能因签名校验失败被拒绝。请先升级服务端，再使用 v0.3.0 客户端；不要仅替换客户端。
旧客户端不声明接收能力，服务端不会向其发送新的提醒消息。

服务器启动须使用 `resona-server serve ...`，自定义 Docker、systemd 或启动脚本中
原先直接传给根命令的启动参数应移至 `serve` 后；其他管理操作见 `resona-server --help`。
完整替换应用包，保留本地配置与凭据。已有配置不会自动重置；本版未改变配置格式版本。
