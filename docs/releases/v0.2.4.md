# v0.2.4 - 桌面交互与语音控制优化

## 功能与修复

- 桌面统一迁移至 GPUI Kit 0.8.1 默认后端，更新文本输入、主题同步和窗口生命周期
  接口，清理旧 GPUI 及不再需要的兼容补丁。保留 Windows 标题栏主题修复。
- 移除工具栏“启用/停用语音”总开关。麦克风只控制发送，耳机只控制收听及提示音；
  关闭收听仍可发言，PTT 与发言指示同步支持。两者关闭时释放设备，设备启动失败
  可直接通过对应按钮重试。
- 聊天消息按本地日期分组，日内显示紧凑的时分秒与昵称，避免窄窗换行及滚动条遮挡。
- 发言显示灰色空闲点和蓝色活动点，区分静音与实际发送/播放。
- 简化服务器连接的中间状态；有效资源更新重新计算五分钟兜底同步期限。
- 修复 macOS 删除服务器书签时的凭据清理失败，保留失败原因和重试入口。
- 修复 Opus ARM NEON 配置及 Rust 构建兼容性，精简 Opus 配置摘要和重复的
  `Up-to-date` 安装输出，保留进度、实际变更、警告与错误。
- 应用打包只在 tag 或手动触发时执行；tag 工作流统一构建并发布全部平台包及签名清单。

## 升级

完整替换应用包并保留本地配置。连接后的自动开麦偏好及自动重连静音保持不变。
耳机按钮现在只暂停收听，若需停止发送，请同时关闭麦克风。
本版没有更改原生传输、认证或服务端资源协议，与 v0.2.3 服务端兼容，无需同步升级服务器。

## 验证与限制

本机客户端 58 项单测、30 项真实 Go/Rust 互通、桌面 65 项单测及 1 项 macOS Block
兼容测试通过；客户端严格 Clippy、格式、构建脚本和版本/锁文件检查通过。
macOS Apple Silicon 签名打包及维护者界面简验通过；语音方向组合、PTT、设备启停、
取消和迟到操作覆盖见 `docs/verification.md`。Windows 和 Intel macOS 以本 tag 的
Actions 构建结果为准；多人连麦、真实设备切换及游戏负载仍需实机验收。
不因框架迁移宣称更低 CPU/GPU 或内存占用。

全部平台构建成功后，Actions 才公开便携包及签名更新清单。macOS 使用已配置的
Apple Development 签名，未进行 Developer ID 公证。
