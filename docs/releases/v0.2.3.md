# v0.2.3 - 登录保持与 Rust 客户端迁移收尾

## 功能与修复

- 登录后正常退出应用，再连接同一服务器时自动恢复账号身份。沿用服务端已有的
  30 天 token，认证成功轮换续期，不增加后台续期定时器，不保存账号密码。
- macOS 使用钥匙串、Windows 使用凭据管理器。凭据绑定服务器书签、地址与
  固定公钥；主动退出账号、删除书签或改变连接目标时清除，忘记服务器密码不影响账号。
- 系统凭据操作独立于语音和控制循环。存储失败显示警告，未响应系统授权不会
  阻塞其他控制或应用退出；失效凭据显式报错并清除，手动重连可作为游客进入。
- 完成 Rust 客户端迁移收尾，移除旧 Go 客户端、音频和专用存储代码；试听机器人
  复用正式 Rust 客户端。共享原生 DSP 与独立编解码参考保留。
- 清理退役 UI 原型说明，更新当前架构文档。

## 升级

完整替换应用包并保留本地配置。首次使用本版需登录一次，后续正常退出可保持
登录；只有重新连接服务器后才确认恢复身份，离线不伪装为已登录。
本版没有修改 Noise UDP 包头或账号认证协议，与 v0.2.2 服务端兼容。
系统拒绝安全存储时不会回退到明文文件。Linux 当前不提供本地安全凭据持久化。

## 验证与限制

客户端 51 项单元、30 项真实 Go/Rust 互通及桌面 56 项单元测试通过。
互通覆盖重启恢复、token 轮换、改密、退出、失效凭据、存储失败和阻塞下的
控制/关闭；本机 macOS 签名构建及维护者简验通过。完整证据见验证记录。
Windows 系统凭据与游戏负载仍待实机验收，不因迁移语言宣称性能提升。

标签 Actions 成功后才公开 Windows x64、macOS arm64/x64 便携包与签名更新
清单。macOS 使用 Apple Development 签名，未进行 Developer ID 公证。
