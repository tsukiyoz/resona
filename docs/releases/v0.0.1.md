# Resona v0.0.1

本版是 GPUI 桌面客户端的首个早期体验版本，不表示 TeamSpeak 功能完全等价。基于 main 的优化分支准备，发布 tag 和 Windows 新包验收独立进行。

- Windows release 主程序使用 GUI 子系统，核心继续通过隐藏的子进程管道运行；打包时验证 PE 子系统，防止再次附带控制台窗口。
- 阈值、音量、降噪、回声消除/抑制与闪避可原位更新，保留音频设备；激活模式、设备、静音/耳聋和频道变化仍走完整切换路径。
- 连续偏好调整合并，等待在途操作后应用最终值；保存移到后台并按版本顺序落盘，退出保存最后值。实际设备失败仍显示，未伪装为成功。
- 查看资料有短延迟合并和有界会话缓存；新选择、加入频道及关闭资料取消过时读取。重复加入被拦截，读取超时使用可理解的提示，真实服务器拒绝仍保留错误码。
- 切频道重建音频不重复提交未改变的静音状态；旧语音操作取消不覆盖新操作的等待状态。
- Windows CI 升级 checkout v5、setup-go v6、upload-artifact v6，使用 Node 24。

macOS：在 desktop 目录构建后，产物为 dist/Resona.app，执行 `open ./dist/Resona.app`。
Windows：完整解压，运行 resona-desktop.exe，保持 core 和附带 DLL 在同一目录。

验证边界：自动测试、打包与真实 Windows/麦克风/服务器验收分别记录。尚未对用户偶发服务端拒绝取得复现日志，不能宣称所有此类错误已解决；权限限制不会因 UI 优化解除。

本轮验证：`go test -race ./internal/...` 全部通过；新增管道测试验证后续详情、加入频道、关闭资料会取消旧查询。Rust 14 项测试通过，包括乱序保存与保存失败重试；macOS release 构建通过，并打开 v0.0.1 离线窗口及音频设置检查布局。本轮未连接真实服务器或采集麦克风，未在 Windows 运行新版。依赖 `block 0.1.6` 仍有 Rust future-incompat 警告，不影响当前构建。
