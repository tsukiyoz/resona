# v0.6.0 - 桌面安装包与 Windows 应用内更新

## 安装与更新

- Windows 新增 Velopack 安装版，提供当前用户安装、快捷方式与系统卸载入口。
  便携 ZIP 继续提供，保留手动下载替换的方式。
- Windows 安装版在「设置 → 关于」手动检查更新；用户确认后下载完整更新包，
  校验签名清单、大小与 SHA-256，再确认退出并安装重启。不在启动或后台自动下载、
  自动应用更新，也不引入空闲轮询。
- macOS 新增 Apple Silicon、Intel 两种 PKG，保留便携 app ZIP。
  本地可运行 `make build-installer-macos` 生成安装包。macOS 暂不开放应用内安装更新。
- 正式 tag 流水线构建各平台便携包、Windows Setup/完整更新包及两种 macOS PKG，
  全部成功后发布 Release 和签名更新清单；缺少任何必需安装包不会发布不完整版本。

## 界面改进

- Windows 字号同时考虑系统 DPI 与屏幕分辨率，避免重复缩放，并适当提升高分屏
  在 100% 系统缩放下的可读性。
- 修复弹窗出现后底层频道界面仍可响应交互的问题。
- 浅色主题采用接近白色的淡灰背景，降低大面积纯白的刺眼感；保留文字、选中状态
  和浮层的清晰层次，深色主题不变。

## 升级与验证

本次不改变 Noise UDP 协议、服务端权限或聊天持久化格式。偏好、书签、账号续登及
系统凭据仍保存于应用目录之外，安装和更新不主动清除这些数据。

维护者已验收 Windows 安装、高分屏/弹窗交互和本地 Apple Silicon 安装体验，
并确认本轮浅色配色。桌面测试、更新/发布保护测试及本地 macOS 构建和安装包检查
通过。各平台正式产物和签名清单以此 tag 的 Actions 成功结果为准。

Windows 安装器目前未做 Authenticode 签名；macOS PKG 未签名且未公证，包内应用
使用现有 Apple 开发证书签名，不能等同于 Developer ID 公证分发。
Intel PKG 安装及 Windows 在两个正式版本间的 OTA 仍需实机验收。
本版本仍为实验性 0.x 预览。
