# 原生连麦验收

## 自动化

`make test-native` 运行 Go 竞态测试与 Rust 测试，使用本机临时目录和 UDP 服务器，不访问用户公网服务。

需要覆盖：公钥和密码拒绝、身份签名及跨连接重放、取消与有界退出、四人同时发送可解码 Opus、无自回传及跨频道隔离、频道 CRUD 权限与持久化、码率同步、资源范围切换、后台合并、聊天和成员瞬时通知。

成员通知须验证初始同步静默、真实加入/离开、对方移动、本人移动静默、范围扩缩和重复列表静默、快速进出不丢事件。旧书签不得发起连接或读取密码；有效原生书签往返保存且信任变化清除目标凭据。

## 实机

1. 记录客户端与服务端版本，两台以上设备连接同一原生服务器；四人场景连续通话至少 30 分钟。
2. 分别发言和同时发言，逐人确认可听见，切频道返回后无旧频道语音。
3. 测静音、收听、个人音量、输入增益、PTT、持续/阈值、在线本地试听及降噪。
4. 管理频道及音质，其他人实时看到变化；成员进出提示正常且重取列表不误响。
5. 后台游戏保持连麦，恢复窗口一次同步；收起栏目及调整聊天输入高度不丢草稿。
6. 断开网络后恢复，记录失联提示时间并手动重连。当前没有自动恢复或无缝网络迁移。
7. Windows/macOS 分别退出，核对 core 和麦克风资源释放。

Noise 静默超时 30 秒，由 5 秒周期检查，不保证即时提示。合成 Opus 测试不是设备听测；静态窗口检查不是 CPU/GPU 性能证明。公网、Windows 和移动平台验收单独记录。
