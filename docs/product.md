# 功能与 GUI 设计

日期：2026-09-07。

## 用户与主要任务

面向希望自托管语音交流、使用频道组织会话、并扩展机器人能力的桌面用户。主要任务是选择服务器、进入频道、交谈与收发消息。GUI 是当前唯一用户界面方向，TUI 不进入首版范围。

## 界面结构

桌面采用固定导航和可伸缩内容：服务器入口 / 频道树、中央聊天、频道详情。窄屏通过收拢导航与详情保留聊天区，避免把桌面三栏强行压缩。

视觉原则：信息密度适合长期使用；中性灰白和 charcoal，teal 表示选中与主要操作，amber 专用于本地预览提醒。浅/深色主题；图标按钮具有可访问名称、焦点态和悬停提示。无营销首页或大幅装饰图。

## M0 工作流

### 服务器书签

字段：名称、地址、昵称。支持创建、编辑、删除。删除需二次确认。保存错误保留表单内容。空地址、空名称、非法输入不能进入存储。

书签是连接目标配置，不代表已经连通。浏览器预览不连接真实服务器，也不保存密码。桌面端密码存于 macOS 系统钥匙串，书签只记录是否记住密码的偏好，不包含密码值。

单击服务器选择书签；双击或服务器行获得焦点后按 Enter 进入服务器。已保存密码时直接连接，没有保存过时打开密码框；成功记住的空密码也支持直接连接。同一服务器已经连接或正在连接时只返回现有会话，不重复发起连接。

“记住密码”默认勾选，之后沿用该书签的选择。仅在认证成功后保存本次密码，错误密码不会覆盖已有凭据。更改书签名称或昵称保留凭据，更改地址或删除书签清除原凭据。编辑书签中提供独立的“忘记已保存密码”操作，不要求删除书签。活跃会话对应的书签仍不能编辑或删除。

### 本地预览

用户主动打开，界面持续显示“本地预览”；浏览器开发模式额外标明“浏览器预览”。预览频道为大厅、音乐、工作间，仅当前频道包含本人。

用户可以切换频道并发送本地消息；消息只存在内存，无服务器广播。离开预览后不能继续发送，重新进入行为保持明确且可重复。消息长度上限为 2000，空消息不可发送。

### 设置

界面主题和显示密度可以即时修改并保存。提示音设置提供总开关、0-100 音量，试听项按“连接服务器、断开连接、成员进入当前频道、成员离开当前频道”排列，默认启用、音量 35。四种音效为项目内生成的短音调，使用系统默认输出，只在本机播放。关闭提示音立即停止当前播放，重新开启不补播之前的事件。没有接入的语音设备功能应省略或明确禁用。

## M1 / M2 真实连接工作流

当前 M1：进入书签 -> 使用已保存密码或输入密码（可为空）-> 连接中/取消 -> 真实频道树与可见成员 -> 点击无密码频道 -> 等待服务器确认 -> 断开。身份自动创建并复用；暂不提供身份选择、真实文字发送、密码频道或语音通话。远端聊天输入禁用，浏览器模式连接按钮禁用。

双击另一服务器或点击其连接按钮表示切换单一会话。先准备目标凭据，再断开旧会话并连接目标；密码框取消、凭据读取失败或偏好保存失败时保留旧连接。新服务器连接失败后显示实际失败状态，不自动连接回旧服务器。尚不提供多个并行服务器会话。

### 频道与成员

频道树展示服务器向当前身份提供的全部频道，保留层级与服务端顺序。每个频道下显示已同步的可见成员，当前用户标记“我”；右侧当前频道成员与树中的成员来自同一份状态。频道树和成员列表所在侧栏可以滚动到底，底部连接状态仍可操作；首次进入会话或本人切频道成功时定位当前频道，普通轮询和他人进出不抢滚动位置。

初始连接完成后异步请求成员订阅。`pending` 表示仍在同步，`ready` 表示订阅命令成功，`limited` 表示订阅超时或被拒绝，仍展示已收到的成员并显示原因。三种状态都只代表当前身份获准看到的范围；订阅成功不保证能看到服务器全部用户。未知或未同步的成员数不显示为确定的零人。

### 连接与凭据验收

| 用户场景 | 预期行为 |
| --- | --- |
| 双击或按 Enter 进入已记住密码的服务器 | 直接发起一次连接，包括已保存空密码的服务器 |
| 未保存密码或主动修改密码 | 打开密码框，使用该书签的记住偏好；取消不改变当前会话 |
| 已在线时进入另一服务器 | 准备好新凭据后断旧连新；始终只有一个会话 |
| 成员同步中或订阅受限 | 区分等待与可见范围受限，已收到成员仍可查看；不伪造完整在线人数 |
| 频道与成员超过侧栏高度 | 最后一项可滚动到达；轮询不会反复拉回当前频道 |
| 已保存密码无法连接 | 失败页提供“修改密码”，允许替换密码或取消记住后单次连接 |
| 准备凭据或保存偏好失败 | 显示错误，保留旧会话和密码输入；修复后可重试 |
| 已成功连接但钥匙串写入失败 | 保持在线，独立显示“已连接，但密码未保存”；不将会话改为连接失败 |
| 忘记密码或改地址、删除书签 | 清除对应已保存凭据；清除失败明确报错，不宣称已经清除 |

已连接时，其他人实际加入或离开当前频道会触发本地提示音。初始成员同步、订阅快照、自己切频道、其他频道变化不提示。主动断开和已建立连接的异常中断各提示一次；取消尚未完成的连接、预览退出和关闭整个应用不提示。窗口退出时优先释放会话与音频资源，不等待退出音播放。

本人成功连接服务器有独立提示音，与成员进入音区分。每次连接完成认证、初始频道和本人信息可用且状态转为已连接时通知一次；连接成功后立即切频道也不丢弃这条成功反馈。其他人登录服务器只按是否进入当前频道判断成员提示，不触发本人的连接成功音。

### 连接体验验收

| 用户场景 | 可见状态与声音 |
| --- | --- |
| 点击连接、认证与同步中 | 显示连接中，可取消；不提前播放成功音 |
| 本人成功建立会话 | 显示实际频道与本人；一次连接服务器提示音 |
| 同一会话重复轮询、成员同步、切频道 | 不重复成功音，不把已有成员当新加入 |
| 刚试听连接音或试听仍在加载时真实连接成功 | 真实成功音不被试听等待或限频吞掉 |
| 连接失败、超时或取消 | 保持实际错误或离线状态；无成功音 |
| 断开后再次成功连接 | 新会话再次提示，旧会话的待加载声音不得迟到播放 |
| 成功音加载完成前已经掉线 | 丢弃成功音，只保留适用的断开反馈 |
| 首次加载已有在线快照、本地预览 | 不播放连接成功音；设置仍可手动试听 |
| 总开关关闭、音量为零 | 无声；重新开启不补播 |

后续 GUI 变更安排产品体验审查，覆盖用户动作、等待、成功、失败、取消和退出，再按这些行为验收。相邻体验建议进入推进计划，不自动扩大当前功能范围。

切换中保留实际当前频道，目标行显示固定尺寸进度图标；禁止重复切换，但仍可断开。收到服务端权限拒绝后显示错误，不伪造进入成功，也不把会话变为离线。密码频道显示锁图标并说明当前不支持。具体频道是否能进入，以服务器响应为准。

打开书签 -> 选择身份 -> 必要时输入密码 -> 连接中 -> 频道与用户同步 -> 进入频道 -> 文字和语音交流。

连接失败显示具体原因；取消连接与断开连接都释放资源。重连状态可见，不重复发送已提交消息。缺少权限时显示实际结果，不仅更新本地 UI。

关键 GUI 状态：首次使用、离线、连接中、在线、无权限、网络断开、重连中、设备不可用、输入验证失败和配置读取失败。

文字范围：频道、私聊；服务器广播按权限另行设计。语音范围：设备选择、麦克风静音、耳聋、输出音量、按键发言/语音激活、发言状态。

## M3 扩展

第一项扩展为音乐：选择本地音频、播放/暂停/停止、队列、当前曲目和音量。先把本地音源跑通，再接在线音源。

插件管理页仅在真实扩展生命周期完成后提供启用/禁用功能。每个外部扩展显示来源、版本和获准能力；启用前明确请求的能力，失败不拖垮客户端。

## 非目标

M0 不实现真实 TS3 网络、音频、假在线人数、自动回复或未来服务端配置页。不承诺聊天历史跨设备同步、音频端到端加密、联邦或与 TS3 完全等价的权限系统。
