# 产品与验收约定

Resona 是面向游戏连麦的语音应用。默认不自动连接服务器或采集麦克风；本地预览和真实网络状态明确区分。

## 服务器与连接

- 添加/编辑表单仅含名称、地址、昵称、服务器公钥；没有传输选择或证书输入。
- 公钥必填，64 位十六进制。错误时保留输入；取消或 Escape 不保存。
- 旧书签保留显示、编辑、删除能力，但不能连接；提示用户使用原生服务器地址及公钥重新添加。
- 读取目标凭据前验证书签。凭据准备失败保留原会话；目标地址或公钥改变后不借用旧密码。
- 连接可取消。失败不能显示成功、保存错误密码或恢复迟到会话。连接成功自动收听，麦克风默认静音。
- 所有者认领和频道管理由服务端授权；普通成员不能靠构造 IPC 或控制帧越权。
- 离开服务器后清空频道与成员；当前会话聊天记录可按既有只读语义保留。

## 音频

支持持续、按键、音量阈值三种发言方式；模式变化不解除静音。PTT 释放、断开、停用及退出清除发送状态。个人收听音量仅针对当前频道其他成员，支持静音和 0–200% 输入，回车确认、越界截断；麦克风增益独立。

在线麦克风试听复用设备，只把本人输入混入本机输出，不发送给其他成员；停止、关闭设置或切频道恢复之前意图，断线/退出取消。后台按键、设备热插拔、声学回声与 Windows 游戏负载必须实机验收。

频道音质为省流 20、游戏 32、高清 48 kbps 或自定义 16–64 kbps，Opus 单声道 48kHz/20ms。改码率不重建设备。子频道、音乐立体声和自动带宽适应不在当前能力中。

## 成员提示

- 仅对已建立会话、本人当前频道其他成员的真实加入/离开生成提示。
- 初次同步、范围扩大/缩小、前台恢复列表、自己换频道不产生批量成员音。
- 每个有序状态在核心中处理，快速加入后离开保留两个事件；通知队列最多 64 条。
- GUI 保留事件 ID 去重、过期过滤、同类声音限频和用户开关。后台收到轻量通知，不重新应用资源列表。
- 退出或新会话不播放旧会话迟到通知。

## 资源与聊天

前台实时事件更新，加五分钟兜底；后台合并普通呈现状态，保留语音、权限、会话及必要命令。恢复时用当前关注范围同步，期间资源操作等待，语音工具栏仍可用。当前实现以窗口是否活跃区分前后台，不是系统遮挡检测。

聊天草稿按书签与频道隔离；Enter 发送、Shift+Enter 换行，失败保留明确状态，结果不确定时显式确认重试。输入框上边界可拖动；正文与底部操作行共用一个外框，发送箭头固定为 32×32px，位于框内右下角，正文不被按钮遮挡。整体高度限制为至少 64px、至多窗口高度 35% 且不超过 280px，窗口缩小时重新限制；最小高度仍保留一行正文，拖动不丢草稿或持续写偏好。验收涵盖按钮点击、Enter、Shift+Enter、中文输入法确认、断线禁用、切频道草稿隔离及最小高度下按钮尺寸稳定。

## 关闭

关闭入口阻止新操作、结束采集和连接，再按设置播放断开反馈。清理与声音等待有上限，核心失联不能阻止最终退出。Windows 注销和真实设备资源释放仍需平台验收。

本轮产品审查覆盖动作、等待、成功、失败、取消和退出。桌面测试通过不等于 Windows 实机或 GPU 性能验收。
