# 功能与 GUI 设计

## Noise 实验验收（2026-09-12）

- 协议明确分为 TeamSpeak 3、Resona (Noise UDP)、Resona (QUIC/TLS)，旧书签不自动迁移，不自动降级。
- Noise 必填 64 位十六进制 X25519 服务器公钥，QUIC 可选 SHA-256 证书指纹；字段独立，切换不互相复制。大小写规范化不清凭据，实际目标或公钥变化先清凭据。
- Noise 验证服务器后才发送密码；未知密钥禁止自动信任，无法区分网络丢包和密钥错误时只提示核对公钥、地址和 UDP。
- 取消与退出不得恢复旧状态、保存密码或启用麦克风；默认收听，麦克风仍关闭。服务器身份初始化不覆盖文件，公钥轮换由用户明确更新书签。
- 接受首版无自动换钥：24 小时或包预算耗尽后需重连；不伪装为自动恢复。原生设备音频、Windows IME 和 WAN 长连接需实机验收。

## 原生服务器实验验收（2026-09-11）

- 旧书签默认为 TS3；新建/编辑可选 Resona QUIC，仅原生模式显示证书指纹。最小窗口表单可滚动，保存/取消和 Enter/IME 行为沿用既有规则。
- 未填写指纹使用系统信任与主机名校验；自签证书显式填写服务器提供的 SHA-256 指纹，不自动接受未知证书，不降级协议。
- 连接等待包括 TLS、密码及初始成员/频道状态；认证失败不显示在线。默认收听、麦克风关闭。取消与退出清理会话，迟到状态不能复活旧会话。
- 协议、地址或指纹变化清理旧凭据，失败阻止保存；读取凭据失败保留原连接，成功认证后才记住密码。
- 原生模式提供真实静态频道/描述、成员、频道文字与语音；没有账号、权限等能力时不伪造相应信息。服务端退出让客户端明确离线。
- 代码流程复核通过；最小窗口实际滚动、菜单 Escape、Windows IME、双机音频及 WAN 测试仍待验收。回环测试不能替代这些证据。

日期：2026-09-08。

## 用户与主要任务

面向希望自托管语音交流、使用频道组织会话、并扩展机器人能力的桌面用户。主要任务是选择服务器、进入频道、交谈与收发消息。GUI 是当前唯一用户界面方向，TUI 不进入首版范围。

长期目标是 Resona 自有客户端、服务端和 Go 扩展生态。TS3 是第一个兼容协议，未来客户端和服务端均以实际互通测试验证 TS 兼容范围。可能增加自研协议，但先用功能缺口、延迟、可靠性或维护成本等测量结果论证，不把更换协议当作阶段完成的前提。

桌面采用固定导航和可伸缩内容：服务器入口 / 频道树、中央聊天、频道详情。窄屏通过收拢导航与详情保留聊天区，避免把桌面三栏强行压缩。

视觉原则：默认石墨深色，参考 Oopz 的紧凑导航、清晰聊天层级和少量亮色，采用适度圆角与局部毛玻璃。冰蓝用于主要操作，薄荷色表示在线，amber 用于预览提醒。浅色仍可选择，新版主题选择独立保存；旧版浅色记录不覆盖新版默认值，不重置显示密度、提示音、密码保存和书签偏好。模糊效果不可用时使用实色底保持可读性。

图标按钮具有可访问名称、焦点态和悬停提示；模态框支持 Escape、焦点约束与关闭后恢复。窄屏的导航、输入、关闭与断开入口保持可达；频道详情可收起，收起不改变会话或消息目标。外观验收同时覆盖连接等待、取消、失败、修改密码、切频道确认和断开后的只读历史。未实现语音功能保持明确禁用。

低资源常驻是产品目标：降低后台 CPU、包含辅助进程的总内存，以及游戏期间窗口最小化后的负载。前端选型按同等连接、频道、成员和消息负载实测，控制模糊范围，不引入常驻装饰动画。目前尚未完成可比测量，不宣称性能已优于 TeamSpeak；候选与评测方案见 [桌面 UI 评估](frontend-evaluation.md)。

## M0 工作流

### 服务器书签

字段：名称、地址、昵称。支持创建、编辑、删除。删除需二次确认。保存错误保留表单内容。空地址、空名称、非法输入不能进入存储。

书签是连接目标配置，不代表已经连通。浏览器预览不连接真实服务器，也不保存密码。桌面端密码存于 macOS 系统钥匙串或 Windows Credential Manager，书签只记录是否记住密码的偏好，不包含密码值。

单击服务器选择书签；双击或服务器行获得焦点后按 Enter 进入服务器。已保存密码时直接连接，没有保存过时打开密码框；成功记住的空密码也支持直接连接。同一服务器已经连接或正在连接时只返回现有会话，不重复发起连接。

“记住密码”默认勾选，之后沿用该书签的选择。仅在认证成功后保存本次密码，错误密码不会覆盖已有凭据。更改书签名称或昵称保留凭据，更改地址或删除书签清除原凭据。编辑书签中提供独立的“忘记已保存密码”操作，不要求删除书签。活跃会话对应的书签仍不能编辑或删除。

### 本地预览

用户主动打开，界面持续显示“本地预览”；浏览器开发模式额外标明“浏览器预览”。预览频道为大厅、音乐、工作间，仅当前频道包含本人。

用户可以切换频道并发送本地消息；消息只存在内存，无服务器广播。离开预览后不能继续发送，重新进入行为保持明确且可重复。消息长度上限为 2000，空消息不可发送。

### 设置

界面主题和显示密度可以即时修改并保存。提示音设置提供总开关、0-100 音量，试听项按“连接服务器、断开连接、成员进入当前频道、成员离开当前频道”排列，默认启用、音量 35。四种音效为项目内生成的短音调，使用系统默认输出，只在本机播放。关闭提示音立即停止当前播放，重新开启不补播之前的事件。没有接入的语音设备功能应省略或明确禁用。

## M1 / M2 真实连接工作流

M1 基线：进入书签 -> 使用已保存密码或输入密码（可为空）-> 连接中/取消 -> 真实频道树与可见成员 -> 加入无密码频道 -> 等待服务器确认 -> 频道文字收发 -> 断开。身份自动创建并复用；暂不提供身份选择、私聊、富文本或密码频道。原生语音范围及本轮新增验收见后文；浏览器模式连接按钮禁用，预览消息仍只在本地。

双击另一服务器或点击其连接按钮表示切换单一会话。先准备目标凭据，再断开旧会话并连接目标；密码框取消、凭据读取失败或偏好保存失败时保留旧连接。新服务器连接失败后显示实际失败状态，不自动连接回旧服务器。尚不提供多个并行服务器会话。

### 频道与成员

频道树展示服务器向当前身份提供的全部频道，保留层级与服务端顺序。每个频道下显示已同步的可见成员，当前用户标记“我”；右侧当前频道成员与树中的成员来自同一份状态。频道树和成员列表所在侧栏可以滚动到底，底部连接状态仍可操作；首次进入会话或本人切频道成功时定位当前频道，普通轮询和他人进出不抢滚动位置。

初始连接完成后异步请求成员订阅。`pending` 表示仍在同步，`ready` 表示订阅命令成功，`limited` 表示订阅超时或被拒绝，仍展示已收到的成员并显示原因。三种状态都只代表当前身份获准看到的范围；订阅成功不保证能看到服务器全部用户。未知或未同步的成员数不显示为确定的零人。

TS3 顶层永久频道中符合 spacer 命名规则的项目显示为空白或标题分隔，隐藏 `[spacer1]` 等控制标记，按协议对齐或重复标题。分隔项不提供加入、人数或锁等频道操作；不满足规则的普通频道名称保持原样。频道自定义图标使用服务器实际资源，未设置、内置图标未映射、下载受限或资源损坏时回退为标准频道图标，锁和当前频道状态独立显示。

图标依次读取有界内存缓存、有效磁盘缓存，最后请求服务器；相同服务器的有效缓存可跨重启复用，不同服务器同 ID 不混用。损坏、过期、不可写和容量淘汰透明降级，不阻断连接和聊天。容量与 TTL 见架构及 ADR-0010，日常界面不解释缓存实现。

原生工作区的普通成员、聊天和语音状态更新不重复传输不变的图标正文。图标首次需要时获取，资源变化后更新；重新连接同一服务器可复用有效资源，切换服务器不得串用同名图标。验收需要 IPC 负载证据，不能仅以网络缓存命中证明这一点。

### 频道与用户详情

点击频道或成员后，详情区显示所选对象的真实资料；查看详情不隐式加入频道。加入频道保留独立明确动作，例如频道双击、Enter 或加入按钮。所选对象与本人当前频道分开标记，聊天和语音仍绑定实际已加入频道。分隔项不作为可加入频道。

频道详情包含服务器实际提供的名称、主题、描述、codec 与质量、永久/半永久/临时及密码等标记、人数上限；客户端详情包含获准可见的身份资料、所在频道、描述和静音等状态。未收到字段与服务端明确为空、零、无限制或继承上级不是同一状态；具体语义以协议映射为准。未获准读取的信息显示不可用或实际拒绝原因，不用默认值伪造资料。描述按安全纯文本呈现，不执行服务端 HTML。

| 详情场景 | 验收要求 |
| --- | --- |
| 点击尚未加载的对象 | 立即标记所选对象并显示固定尺寸等待状态，已有聊天和语音不中断 |
| 请求成功 | 标题和资料来自同一对象、同一会话，不把旧对象资料短暂放到新标题下 |
| 快速改选、切服务器或断开 | 旧请求结果不能覆盖当前选择；取消等待不要求撤回已经发出的协议请求 |
| 权限拒绝、超时或对象离开/删除 | 详情显示对应原因或已离开状态，允许适用的重试，不把会话改成离线 |
| 查看其他频道或成员 | 不移动本人、不改变发送目标，也不把选择态显示为加入成功 |
| 退出应用 | 取消在途详情处理，不为等待读取结果延迟退出 |

### 频道文字聊天

本轮仅支持本人已加入频道的纯文本收发。正文按文本呈现，不执行 HTML、不解析 TS 富文本标记；私聊、服务器广播、附件、消息编辑与撤回、已读和消息通知音留待后续。真实频道消息按 UTF-8 字节数限制为 8192 字节，服务端仍可能施加更小限制；空消息和非法文本不能发送。Enter 发送，Shift+Enter 换行，输入法组词时 Enter 不提交。

发送动作绑定提交时的会话 ID 和频道 ID。一次只允许一条在途消息，发送中暂禁输入和本人切频道；切频道待确认时不能发送，断开仍可操作。草稿按服务器书签和频道保存在当前进程，切频道和掉线不会清空；仅成功发送后清除对应的原草稿，失败或结果未确认保留原文。旧会话的迟到结果不得清除新会话草稿。

消息显示作者、时间和状态：`sending` 为发送中，`sent` 仅代表服务器接受，`failed` 为明确未发送或被拒绝，`unconfirmed` 表示结果未知且可能已经送达，收到的远端消息为 `received`。不自动重试；明确失败可手动重试，未确认消息需用户确认可能重复后重发。重试限于当前连接的原频道。自身协议回显不重复生成本地消息行，主动连续发送相同文本仍是两条消息。

历史属于本次连接，跨频道合计最多保留最近 500 条；切回频道可查看先前内容。断开或掉线后可只读浏览原频道记录，不保留在线成员假象；开始新连接或本地预览时清空上一连接的历史。退出应用不保存历史或草稿。收到消息时仅在用户已接近底部时自动滚动，避免打断历史阅读。

TS3 实际按服务端处理命令时的本人频道发送，不能通过 `target` 字段强制指定旧频道。本地操作串行和发包前检查可以避免本客户端主动切频道造成的误发，但管理员等外部强制移动仍存在无法由该协议原子消除的竞争条件，不能承诺绝对指定频道投递。取消等待也不等于撤回已经发出的消息。

| 聊天场景 | 验收要求 |
| --- | --- |
| 正常发送与接收 | 服务端接受后显示已发送；对端文字仅进入实际接收频道，自身回显不重复 |
| 中文输入与换行 | 组词 Enter 不提交，Shift+Enter 保留换行；正文按纯文本显示 |
| 权限、长度或频率拒绝 | 消息显示具体失败，原文仍可恢复，连接继续有效 |
| 超时或发送中断线 | 标记未确认，不自动重发；手动重试前确认可能重复 |
| 本人主动切频道 | 与在途发送互斥，旧频道草稿不流入新频道 |
| 断线与重新连接 | 原记录只读，新连接清空旧历史；迟到结果不污染新会话 |
| 浏览历史时收到消息 | 不抢滚动位置；用户回到底部后继续跟随新消息 |

### 连接与凭据验收

| 用户场景 | 预期行为 |
| --- | --- |
| 双击或按 Enter 进入已记住密码的服务器 | 直接发起一次连接，包括已保存空密码的服务器 |
| 未保存密码或主动修改密码 | 打开密码框，使用该书签的记住偏好；取消不改变当前会话 |
| 已在线时进入另一服务器 | 准备好新凭据后断旧连新；始终只有一个会话 |
| 成员同步中或订阅受限 | 区分等待与可见范围受限，已收到成员仍可查看；不伪造完整在线人数 |
| 频道与成员超过侧栏高度 | 最后一项可滚动到达；轮询不会反复拉回当前频道 |
| 已保存密码无法连接 | 失败页提供“修改密码”，允许替换密码或取消记住后单次连接 |
| 准备凭据或保存偏好失败 | 显示错误，保留旧会话和密码输入；修复后可重试 |
| 已成功连接但系统凭据写入失败 | 保持在线，独立显示“已连接，但密码未保存”；不将会话改为连接失败 |
| 忘记密码或改地址、删除书签 | 清除对应已保存凭据；清除失败明确报错，不宣称已经清除 |

已连接时，其他人实际加入或离开当前频道会触发本地提示音。初始成员同步、订阅快照、自己切频道、其他频道变化不提示。主动断开和已建立连接的异常中断各提示一次；取消尚未完成的连接和预览退出不提示。关闭应用时，先停止采集与发送、取消在途操作并断开服务器，再按提示音偏好完成一次断开反馈，最后退出；详细时序和超时要求见原生退出验收。本轮要求取代此前“应用关闭静默且不等待声音”的约定。

本人成功连接服务器有独立提示音，与成员进入音区分。每次连接完成认证、初始频道和本人信息可用且状态转为已连接时通知一次；连接成功后立即切频道也不丢弃这条成功反馈。其他人登录服务器只按是否进入当前频道判断成员提示，不触发本人的连接成功音。

### 本地麦克风测试与发言激活

本地麦克风测试通过明确的开始/停止操作采集并回放所选输入，离线也可使用。界面持续标明本地测试状态；测试音频不录盘、不发送到 TS3，不生成网络发言状态。首次开始测试或明确解除麦克风静音时才请求系统输入权限，进入设置、连接成功、改变模式或阈值均不隐式打开输入。

测试与真实发言必须互斥。在线测试保留服务器连接和频道接收，在同一音频引擎内关闭网络发送，将采集结果混入本机输出；保留当前收听音量。测试期间锁定音频设置，等待此前排队的配置完成后才能开始。显式试听临时解除耳聋以播放本人输入，停止后恢复此前的启用、静音、耳聋和激活设置；不持久保存临时状态。停止或关闭设置立即关闭试听采集门，再异步恢复设备；启动过程中停止同样有效。按键发言恢复后必须重新松开并按下，不能靠重复按键恢复发送。

拒绝权限或启动失败显示错误，最多恢复一次静音播放，不重试打开被拒绝的麦克风，不恢复网络发送，不改变文字会话。设备操作超时解除等待状态并隔离迟到结果。切频道取消测试并在新频道恢复此前设置；断开、切服务器和退出取消测试，不在旧会话恢复设备。

发言激活使用按键发言、持续发送、语音检测三种明确模式。三种模式均受显式麦克风静音、耳聋和设备故障约束；选择模式或恢复保存配置不解除静音。持续发送仅在用户解除静音后发送；语音检测依据实际输入和可调阈值开闭发送门，需有避免句尾截断和阈值附近抖动的策略。显示的输入电平必须来自实际采集，不能把阈值或随机动画当电平。

| 音频设置场景 | 验收要求 |

### 音频处理

用户要求回声消除、键盘/背景噪声抑制等级和音量衰减。设置应反映实际后端能力：回声消除采用开关，抑制采用明确等级选择，衰减强度采用数值控件。未实现或平台不可用的处理明确禁用，不能接受设置后无效果；初始化失败显示原因，未处理音频不得被标为已处理。

回声消除的验收包含真实输出参考与采集路径，不能把单纯降低麦克风增益叫作回声消除。背景/键盘噪声抑制须说明实际能力边界，并以相同输入对比各等级的输出；不能把简单发送门当成已实现噪声消除，也不能承诺所有键盘声均可消除。

音量衰减需要清楚标出作用对象和触发条件。若实现作用于本应用收到的频道音频，只可描述为本人发言时降低频道播放音量；其他应用的系统音量衰减属于不同平台能力，未接入不得暗示已支持。停止发言、静音、耳聋、故障或停用后恢复原输出音量，不永久改写用户音量偏好。处理失败不破坏文字连接，切设备、切频道和退出均清空旧处理状态。

### 原生退出验收

关窗、应用退出命令和系统正常退出入口采用同一流程，重复请求不重复断开或播音。开始退出后拒绝新的连接、发送、设备及测试操作，立刻停止麦克风与本地测试，取消在途连接/详情/设备工作，完成服务器断开，再等待适用的本地断开音结束，最后回收 Go 核心和窗口。等待期间界面保持响应并呈现正在退出；无需额外确认。

仅退出已建立的真实会话播放一次断开反馈；离线、预览、未完成认证的取消保持无声。遵循提示音总开关、音量为零及耳聋偏好，不因退出临时取消用户无声设置。播放请求入队不等于播放完成，正常路径必须等待真实完成结果；声音失败、核心已退出或清理超时必须有有界兜底，不能因声音或服务器不可达永久留住进程。强制终止进程和操作系统强杀不承诺播放反馈。

验收覆盖在线、离线、本地测试中、输入设备启动中、连接中、正在切服务器、核心异常及重复退出，并核对主进程、核心辅助进程、设备和网络连接释放。真实服务器动作仅在 Resona 专用测试频道验证。

### 本轮能力与验证边界

本节定义已接受的交付需求，不代表实现或验收完成。全局按键发言的 macOS/Windows 权限与后台可用性、回声消除的参考信号路径、噪声抑制后端和等级效果、音量衰减作用范围、服务器详情字段可见权限及退出超时都必须随实现记录真实支持状态与证据。构建通过和模拟输入测试不能替代实际设备、桌面按键、专用频道或同负载 release 资源测量。仍未实现的能力保持明确不可用并记录为未完成，不据此勾选整个 M2。

### 语音活动指示行为

频道树与成员列表使用同样大小的成员语音图标，有声音时亮起，停止后约 300ms 熄灭（最迟 500ms），不改变行高。图标表示音频活动，不是可点击的静音按钮，也不宣称识别人类语音。

远端由成功解码的有声帧触发，本人由实际成功发送的有声采集帧触发。仅开启麦克风不常亮；活动指示检测本身不改变发送策略，发言门由上述激活模式独立控制。音量为零仍显示远端活动，空包、无效包和丢包补偿不刷新指示。自身静音熄灭自身；耳聋、停用、断开、故障清除全部，恢复后须有新音频才亮。成员离开和频道切换清除旧状态，仅当前会话当前频道的已知成员可亮。

核心只推送活动状态变化，不把逐帧 PCM 或音量数据发送给 GUI。验收覆盖两处列表一致、静音仍能显示别人说话、停止后熄灭、断线与旧频道状态不残留。

## v0.0.1 体验优化验收

- Windows 发布包双击仅显示应用窗口；核心启动失败在 GUI 报错。正常关窗回收 GUI 和核心。debug 构建保留控制台诊断；CI 检查 release PE 子系统，实机确认无窗口闪现。

- 自动验证覆盖音频原位更新不重建设备、不重复静音命令、最终值和取消、DSP 与回调并发、频道重建旧队列隔离、详情取消及缓存实体失效。Windows 双击/无控制台/卡顿和专用频道错误场景仍需实机确认。

### 两级服务器导航验收（2026-09-10）

- 服务器列表独立纵向滚动，第三个及更多书签不得被裁掉；添加入口固定在服务器栏底部。编辑/删除通过书签右键菜单操作，绑定右键对象，不触发连接或切换查看选择；收起栏同样可用。聚焦书签后F2打开编辑，菜单Escape/点击外部取消，删除仍需确认。
- 服务器栏可缩至52px图标栏，频道栏可缩至44px；两栏独立收起和恢复，并保存偏好。单击书签会展开频道栏；完整名称可通过悬浮提示查看。
- 单击只查看书签。双击、Enter或显式连接按钮才连接；忙碌时不重复发起。选择未连接的B时不展示A的频道，聊天和语音仍属于实际会话A，聊天副标题标明会话服务器。等待中改选C，B的迟到连接结果不得抢回查看选择。
- 断开成功或连接失效后，频道树和成员列表不再显示旧快照，恢复连接入口；保存的服务器书签保留。退出本地预览同样清空频道树。
- 本地预览仅debug构建显示入口和引导文案；release打包隐藏。预览有明确标记，查看真实书签不借用预览频道。当前真实会话未断开时不直接用预览覆盖连接。

### 麦克风输入增益（2026-09-11）

- 设置 → 语音与设备中提供麦克风输入增益0–200%、10%步进和恢复100%。旧配置缺省100%；显式0表示无输入声音，与麦克风静音开关独立。
- 在线语音、离线试听、连接中试听共享增益处理。先做DSP并取得VAD判定电平，再应用输入增益和样本限幅，最后编码或回放；试听电平显示增益后、收听音量前的信号。增益不改变语音检测阈值含义，也不保证放大弱信号能改善信噪比。
- 调整不重开设备、不解除静音/耳聋、不改变PTT按键状态、不修改系统麦克风音量；试听中可热调，停止试听恢复原发言意图但保留最新增益。
- 同时仅接受一个增益调整，等待期间显示“应用中”，确认后更新数值并保存到原生偏好；失败保留原值并就近提示。退出保存已确认值，未确认请求不阻止退出。频道/设备切换期间不可调。
- 验收覆盖0/100/200%、限幅、网络编码与两种试听一致、0值保存重载、旧配置默认值、VAD门限不变、设备打开次数与PTT不变。真实麦克风声学质量和Windows使用体验需实机验收。

### 单成员本地收听控制（2026-09-11）

- 右侧资料中的音量百分比可直接填写整数，回车确认。负数限制为0，超过200限制为200，超长整数同样限制；百分号为输入框外的单位。空值、小数、科学计数法和混合字符就近提示，不修改实际音量。
- 输入法候选确认不提交；请求等待时输入和按钮禁用，相同已确认值不重复发送。失焦/关闭资料/切换成员丢弃草稿，不隐式应用；失败恢复已确认值并显示原因。填写音量不解除本机静音。

- 频道成员支持右键菜单直接静音、增减10%、恢复100%，以及0/50/100/150/200%档位。右键和取消菜单不改变资料选择或加入频道；原资料栏控件保留。
- 本人行不挂载收听右键菜单（包括本地预览本人），右键不显示音量或静音操作，不改变资料选择、不发送请求；左键仍可查看本人资料。单人成员收听不用于麦克风输入增益或本地麦克风测试。
- 菜单执行时重新核对会话和成员实例，增减基于最新确认音量、保留最新静音状态；失效或失败在菜单关闭后仍显示目标明确的提示，不自动打开资料。其他频道和切换/等待期间菜单不可调。取消菜单不改变设置，断开或退出后不执行遗留操作。

- 单击当前频道的其他成员，在资料栏调整收听音量：0–200%，默认100%，每次增减10%，可恢复100%。本人不显示此控件；无语音能力、非当前频道或切换频道期间不可操作。
- 本机静音独立于音量，取消静音恢复原音量；调整或恢复音量不解除静音。成员列表用耳机关闭图标标记本机静音。总收听音量、耳聋和混音限幅仍生效。
- 同时仅接受一个调整请求，等待确认后显示新值；失败保留已确认值并在该成员处提示。切换查看对象不显示前一个人的错误，迟到回复不得覆盖成员列表或其他成员设置。
- 资料加载或服务端拒绝资料权限不阻止本地调节。关闭资料页不撤销已提交操作；设置不修改服务端权限、不重开音频设备、不启用麦克风。
- 设置只保留在本次连接的成员实例中：改名、移出后返回同一频道保留；成员离开后重新进入、断开重连恢复默认，不持久化到磁盘。
- 验收包括A静音时B不变、0/100/200%与恢复、静音期间调节、同ID同昵称的新实例不继承、请求失败和迟到回复，以及最小窗口控件可达。Windows实机听测待验收。
