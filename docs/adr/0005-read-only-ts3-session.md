# ADR-0005：只读 TS3 会话与持久身份

- 日期：2026-09-07
- 状态：Accepted
- 细化 ADR-0003，不表示完整 M1 或语音兼容性通过。

## 背景

候选库已能连接授权测试服务器，但主动频道查询遭到权限拒绝。源码没有暴露登录推送的完整频道树；现有高层成员回调异步执行，不能作为有序状态流。首个真实 GUI 切片需要准确显示服务器状态和管理连接生命周期。

## 决定

固定 `github.com/honeybbq/teamspeak-go` 的 `a334def898f4d9c518a1434a9b9e9f889dcae954`，将已跟踪源码放在 `third_party/teamspeak-go`，保留 MIT LICENSE，通过根 module 的 replace 引用。上游模块是第三方快照，不代表提前拆分 Resona 的业务模块。来源和补丁在该目录 RESONA.md 记录。

最小补丁只增加构造时注册的同步 CommandObserver：命令解析成功后、原有分发前调用，各观察者接收复制的 Params。观察者不得阻塞等待网络命令。Resona 适配器按该顺序归并频道和用户；不解析日志，不访问私有 transport，也不把上游类型交给 GUI。

另修正上游昵称推测覆盖已知 client ID 的路径：收到 `initserver` 后，名称为 `Resona123` 的其他用户不能改变本连接的 client ID。昵称匹配只在尚无 client ID 时作为上游兜底，附回归测试。

初始频道使用 `channellist` / `channellistfinished` 推送。频道父级字段为 `cpid`，顺序字段表示前一个同级频道的 ID，不能简单当作数值序号排序。只有 `initserver`、频道结束标志和本人所在频道信息均收到才完成连接；其他成员继续流式更新。只显示已可见成员，不发送全频道订阅或权限查询；频道副文本使用推送中的 topic，缺失时为空。

真实远端切片为只读：不发送文字、音频、频道切换、管理命令。协议握手、心跳、本人静音状态更新和主动断开仍必需。适配器强制本人输入/输出静音，不访问麦克风或音频设备。

应用核心只依赖 Connect/Close 和 RemoteState 回调。连接超时 30 秒，每次使用新的 transport 和 session generation；取消、迟到成功、服务端关闭与窗口关闭均回收连接。地址先通过可取消 DNS/SRV 解析为数值 endpoint，再进入上游 Connect，暂不接入 TSDNS/MyTeamSpeak 或自动故障转移。

默认创建安全等级 8 的独立身份，存入 `os.UserConfigDir()/resona/identity.key`，权限 0600。并发创建通过临时文件与不覆盖的原子链接解决；重连加载同一个私钥，损坏文件不覆盖。系统钥匙串、官方身份导入和交互式安全等级升级留待后续。服务器密码只在此次连接内存中使用，不写配置或日志。

## 代价与重新评估

需要维护一个明确、可审查的上游快照，并独立运行其测试；根 `go test ./...` 不遍历嵌套模块。后续升级必须重新验证补丁、握手和状态流。

此阶段不宣称所有频道的完整成员数、语音、文字收发、自动重连、所有安全等级或所有 TS3 版本兼容。测试服务器外的互通矩阵与长期运行仍未完成。若上游提供等价观察接口，删除本地补丁并改为固定发布依赖；若生命周期或协议缺口扩大，重新评估维护分支或替代实现。
