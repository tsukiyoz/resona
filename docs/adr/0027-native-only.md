# ADR-0027：单一原生协议与成员通知

日期：2026-09-15。状态：Accepted。

## 决定

产品只使用 Noise UDP、Protobuf 控制和 Opus 语音。删除其他传输入口、第三方实现、专属信任配置、协议选择界面及历史对比文档，不保留运行时回退。当前仍在同仓库开发配套客户端与服务端，允许同步破坏性升级。

保留小型 RemoteConnector/音频 Transport 接口以隔离客户端、设备、测试和未来嵌入边界，不为单一传输维护路由器。持久书签的 protocol 标记只用于拒绝不支持的配置，不向用户提供选择。旧记录不自动转换为新目标，不读取其密码，不中断原会话；可删除或重新填写原生公钥。

## 成员通知

在原生客户端处理每个递增 revision 时，比对前后同一当前频道的成员 ID 与实例。初始快照和本人频道变化静默；当前频道在所有订阅范围中均完整存在，因此扩大/缩小范围不制造进出事件。

每次真实加入/离开分别生成 RemoteEvent，再经已有的会话过滤和有界通知队列传递。后台只发送轻量通知。资源状态可合并，瞬时事件不能只按最终状态合并；快速加入后离开保持两个事件。关连接后的迟到事件由会话代数与 GUI 去重/过期检查隔离。

## 验收与限制

本机验证信任失败、取消、多人音频、频道权限与状态、资源同步和通知。Windows 游戏实机、长时间网络故障和音频听测仍需独立完成。自动重连和管理员委派为下一切片，不因删除旧代码而宣称完成。

删除文件不会改写 Git 历史，也不会自动清空用户配置或旧发布产物。后续按用户授权升级远端并发布 v0.1.0；部署数据和旧容器保留用于回退。
