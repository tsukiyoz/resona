# ADR-0013: 独立图标引用与按需详情

2026-09-09 v0.0.1 补充：GUI 延迟200ms合并资料选择，IPC 后续资料选择、频道加入或显式关闭取消旧资料查询；图标读取互不取消。适配器按会话、目标、实体版本缓存成功结果10秒/服务器拒绝2秒，最多64项，限制重复点击触发协议命令。超时与取消转换为用户提示，拒绝错误码保留，不能据此声称权限问题已修复。

- 日期：2026-09-08
- 状态：Accepted
- 补充 ADR-0009 / ADR-0010 / ADR-0011，替代频道快照携带图片正文的设计。

应用入口创建 `iconcache.Cache` 并注入 TS3 Connector。连接只持有下载队列、授权范围及取消生命周期。缓存继续复用已有校验、磁盘存储、TTL 和容量限制，不新建通用资源框架。

`Channel.iconRef` 是隔离服务器、身份、端点和转换版本的非明文引用。Workspace 与协议归并状态只携带引用。`GetIconResource(sessionID, ref)` 验证当前真实连接和当前可见频道引用，返回单张 PNG data URL；该读取不触发网络下载。重复状态更新不重复传送图片正文。Wails 和 GPUI 都经集中桥接单独获取资源。

`GetChannelDetails` / `GetUserDetails` 使用协议无关的可选读取能力，TS3 适配执行真实 channelinfo/clientinfo 查询。应用层最多四个并发读取，八秒超时，断开取消，结果检查会话代数与实体版本。目标复用 ID 不接受旧结果。缺失字段保持未知；成员数表示当前授权可见成员，与订阅完整性一起呈现。主题与描述分离，描述以纯文本显示，不下载其中的外部图片。

普通频道单击查看详情，双击或 Enter 加入；查看详情不改变音频频道。读取失败只影响详情，不断开会话。

保留有界 Go 内存缓存作为现有实现，后续按等负载测量决定是否关闭或缩小。GUI 解码图像、操作系统页缓存与 Go 缓存分别统计，不将序列化缩小量等同于内存节省。验证见 verification.md。
