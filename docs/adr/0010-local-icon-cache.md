# ADR-0010：有限内存与本地图标缓存

- 状态：Accepted
- 日期：2026-09-08
- 扩展：ADR-0009

## 背景

频道图标在重连和应用重启后仍可复用。此前只在单次连接内去重，重新连接会再次下载。缓存必须有容量、有效期与身份隔离边界，且缓存故障不能导致连接失败。

## 决策

新增专用 `internal/iconcache`，由桌面 TS3 Connector 持有并跨连接复用。读取顺序为有限内存、磁盘、实际服务器文件传输；缓存未命中、过期或损坏时继续下一层。只缓存经过图像验证与缩略处理的静态 PNG，不保存任意原始下载文件。

- 内存 LRU 最多 128 项、8 MiB；此限制只约束缓存层，不表示整个应用或会话快照的内存上限。
- 磁盘完整缓存记录最多 512 项、64 MiB，位于 `os.UserCacheDir()/resona/icons`；正常写入后淘汰旧记录。删除失败时尽力继续清理其他记录。配额不包含进程硬崩溃留下的临时文件，本轮尚未实现此类文件的定期清理。
- 有效期从写入起固定 7 天，命中不延长。过期后重新获取服务器资源。
- 键绑定协议、可用的服务器 UID、规范化服务器地址、实际连接端点、客户端身份 UID、图标 ID 与转换版本。客户端 UID 只用于身份权限边界，不能代替服务器 UID。地址或解析端点变化可能产生冷缓存。
- 目录与文件按平台能力使用 0700 / 0600；完整记录经临时文件和原子替换发布，避免取消或写入中断留下半个有效条目。
- 缓存 I/O 在图标 worker 执行，不在同步协议观察回调或持有连接锁期间进行。
- 磁盘不可用时降级为内存和网络；不持久化下载失败，不让一次失败阻止后续连接重试。

GUI 继续接收经过验证、最多 256 KiB、256x256 像素的 PNG data URL，资源不可用时使用标准频道图标。缓存实现与路径不进入日常界面文案。

## 影响

热缓存减少重复传输，磁盘缓存支持进程重启后复用。缓存不是离线服务器数据副本，命中也不绕过正常会话认证；不保存密码、私钥或聊天历史。固定 TTL 意味着同一键对应资源被服务器替换时，可能在有效期内显示旧图。

本轮只实现已经存在的图标需求，不建立通用资源平台。未来头像等资源接入时，分别定义键、验证、权限与过期策略，再决定是否共享实现。

## 验证

用可计数的下载函数和临时缓存目录验证内存命中、重新创建缓存实例后的磁盘命中、TTL、损坏恢复、容量淘汰、身份隔离、取消与磁盘失败降级。并发行为使用 race 检查；无需连接用户服务器验证缓存策略。
