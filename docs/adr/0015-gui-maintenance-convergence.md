# ADR-0015: GUI 开发收敛与冻结 Wails 基线

2026-09-10：保留 Wails 的维护决定已被用户明确授权的 ADR-0016 替代。以下为历史依据；Windows 测量与验收要求仍有效。

- 日期：2026-09-09
- 状态：Accepted（可逆维护策略，不是最终删除或跨平台性能验收）
- 关联：ADR-0002、ADR-0011；数据见 docs/frontend-evaluation.md。

用户要求尽早比较性能，避免长期维护两套前端。首轮预览原生物理占用约 74 MiB，Wails 约 98 MiB，但最小化状态后来确认为被观察工具恢复，不能用于后台结论。修正后的真正最小化离线复测为原生约 48 MiB / 0.30 次唤醒每秒，Wails 约 104 MiB / 51 次；详见 wakeup-investigation.md。这些简单场景不代表通话和游戏性能已验收。新音频和资料功能已集中于 GPUI。

后续新增 GUI 功能只在 GPUI 实现。Wails 冻结为可构建、可测量的回退基线；共享 Go 改动保持其构建兼容，仅为构建/测试阻断或必要安全修复修改旧 GUI，不重复补齐新功能。不删除 frontend、Wails 入口和构建链，不新增第三个候选。

删除 Wails 的条件是 Windows 同负载语音与游戏指标、主要交互/权限/生命周期验收完成，并据此另作最终迁移决定。最小化高唤醒已查明是测量干扰，不作为未修复产品缺陷。若 GPUI 不满足产品资源约束，以测量热点决定修复或回退；冻结策略不预先保证其成为最终方案。
