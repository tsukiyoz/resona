# ADR-0014: 音频控制、本地试听与有界退出

2026-09-16 收听增益：全局默认约 +6 dB，个人默认 0 dB，GUI 两层统一 -20 至 +18 dB、1 dB 步进，静音独立。IPC 继续传线性百分比整数（最大 794），保留原值语义与实时路径的简单乘法；此范围内整数 dB 可往返换算。专用 SetOutputGain 按会话验证，仅在无生命周期操作时同步发布配置，成功回复后 GUI 保存全局偏好，连接前恢复；排队的静音配置刷新已确认增益，不能写回旧值。个人缓存保持成员实例边界。混音末端以整帧峰值计算限幅系数，立即压低、约 200ms 恢复，无额外缓冲、锁和动态分配；未过载稳态保持原样。不是自动增益/响度归一化，录音已削波无法修复。输入增益及通知音量保持独立。

2026-09-11 输入增益：新增0–200%的`inputGain`，IPC缺省100、显式0保留。正常设置沿用配置快照；`SetInputGain`专用命令在Service锁内确认无生命周期切换，再尝试无等待取得引擎控制令牌，只发布新配置，不接触设备或发送门。离线测试、在线测试与普通语音均支持；在线测试同时更新恢复配置。DSP后先计算VAD判定电平，再乘增益并限幅至[-1,1]，然后读取试听电平、编码或回放。GUI确认成功后持久化，试听期间仅输入增益例外可调，其他设置仍按原规则禁用。

2026-09-09 v0.0.1 补充：同一设备、静音/耳聋及激活模式下的音量、阈值、闪避使用原子配置快照更新；DSP 在控制路径准备后于处理锁内替换，设备回调不等待该锁。完整设备/模式/频道切换仍停止旧实例。频道重建成功时不重复提交未改变的服务器静音状态；故障恢复仍重新同步。GUI 合并偏好并后台串行保存，退出落盘最后版本。

- 定义原生音频控制与退出反馈的生命周期。

每次真实连接成功后自动启动输出一次，保留音频配置但强制麦克风静音、取消耳聋。会话代数和同一锁内的配置准入检查防止迟到启动。用户本会话停用后，成员更新不重新启用。设备失败保留文字连接和明确语音错误。

三种激活方式为持续传输、按键发言、音量阈值检测。切换模式不解除静音。PTT 是瞬时状态，不写入持久配置；释放、停用、断开、监听故障和退出关闭发送门。阈值检测使用实际 PCM 电平与释放延迟，不声称识别人声。游戏后台按键依赖操作系统全局快捷键能力，权限与注册失败必须可见。

离线/本地预览允许用户显式启动麦克风试听，独立音频实例不持有网络 Transport，处理后送本机输出。连接准入、停止试听、关闭设置或退出取消并回收实例。仅试听推送最多 10Hz 的电平，正常语音不通过 JSON 传逐帧样本。试听不服从网络 PTT/VAD 发送门，避免误以为输入设备无声。

2026-09-10 扩展：已连接时复用现有语音引擎，以内部 `LocalMonitor` 配置关闭网络发送并保持远端解码/混音。本地 PCM 使用仅在测试期间分配的有界独立环形队列，在同一输出回调混入频道音频；不增加设备实例或音频 IPC。进入/退出测试走串行设备切换，过渡期间可能短暂中断输出，不承诺无缝音频。开始继承当前收听音量，保存原语音意图；停止和关闭设置恢复，切频道在新频道恢复，断开/退出仅取消。测试失败最多回退到静音输出一次；15 秒设备截止时间解除等待并隔离迟到操作。PTT 物理按键边沿独立于发送状态，测试结束要求释放后重新按下。GUI 在测试期间禁用音频配置，开始前等待已有配置完成。详细验收见 product.md。

DSP 采用 SpeexDSP 1.2.1 的 BSD 源码子集，源码归属、固定归档 SHA-256、构建配置见 `internal/audio/speexdsp/README.md`。48kHz 单声道、20ms 帧、200ms AEC 尾长。降噪低/中/高对应 -10/-20/-30dB；回声抑制使用自适应回声参考，不是简单音量开关。回声参考来自 Resona 实际输出回调，包含本应用收听音量和闪避，不涵盖其他应用与独立提示音播放器。

通用统计降噪可能降低部分键盘声，但不是键盘事件分类器，不保证消除瞬态敲击。闪避只将本人有声发送期间的本应用接收语音衰减至 25%，不控制游戏或其他应用。合成衰减测试不替代房间声学、设备时钟及游戏性能测试。

原生正常退出拦截关窗和 Cmd-Q，阻止新操作，PrepareShutdown 关闭测试和网络采集并等待服务清理。仅实际在线、提示音启用、非耳聋、音量非零时播放一次断开音。播放完成意味着设备回调已消费最终缓冲并经过短排空窗口，不是仅进入队列。核心清理最多等待 3 秒、提示音最多 2 秒；GUI 另有最终超时/子进程回收。无声偏好、音频失败、核心失联不能阻止退出。异常强制终止不保证播放反馈。

产品音频控制和优雅提示音退出验收针对 GPUI。

全局按键采用固定版本 global-hotkey 0.8.0；注册失败展示错误并提供窗口内按键回退。常规关窗和 Cmd-Q 异步等待；GPUI 系统退出回调仅提供很短的异步等待窗口，因此系统退出入口同步有界等待最多 7 秒，再同步回收核心子进程。该入口等待期间不承诺窗口响应。核心回复读取不依赖 GUI 继续消费普通事件，避免满队列阻止退出确认。
