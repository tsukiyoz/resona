# ADR-0028: 可取消重连与有界客户端诊断

日期：2026-09-15。状态：Accepted。

## 重连

仅成功连接后的意外传输断开自动重连，首次连接失败保留手动处理。沿用 Noise 的现有心跳与约 30 秒无接收超时，不另建探活循环。单个可取消 worker 负责旧资源回收、退避和连接；退避约 1/2/4/8/16/25 秒加最多 20% 抖动，总间隔不超过 30 秒，一次只运行一次连接尝试。连接建立后没有重连计时器。

会话内暂存已成功使用的密码，断开、终止重试和退出后解除引用，不逐次调用系统密码存储，不写入工作区或日志。明确身份验证或服务端拒绝停止重试。纯 UDP 无响应无法可靠区分断网、旧协议或服务端换钥，此时继续可取消退避，不声称已识别具体原因。

恢复期间状态暂存于尝试内，原频道恢复完成后才发布新连接；恢复过程中再次断网继续重试。新会话 ID 使资源订阅重新建立，代数阻止旧回调、请求和硬件完成覆盖新会话。原频道不存在或拒绝进入时留在服务端当前频道并提示。设备、音量、增益、发言模式和收听静音保留；麦克风始终静音，PTT 需要重新按下，试听不恢复。禁止自动重发聊天、管理或认领命令。

取消、切换服务器和退出通过同一关闭入口取消计时器及连接。编辑当前目标必须先取消连接。后台不推送逐秒倒计时，只有状态变化。

## 日志

core 的 slog 写入预分配结构化内存环：512 条、最近 15 分钟，两个上限以先到者为准。每条最多 10 个字段，键最多 32 字节，文本值最多 96 字节，消息最多 64 字节；只接受审核过的事件/字段和原始值类型，不执行任意 LogValuer 或 error 格式化。环内不持有外部字符串/对象。容量满覆盖最旧记录，记录时淘汰过期项，导出也按时间过滤；不额外启动清理计时器。统计容量覆盖与锁竞争丢弃，旧内存槽无需定时清零。

写入使用 TryLock，快照复制或其他写者持锁时立即丢弃并计数。只在用户点击导出时分配快照、编码 JSON 并写本机缓存目录下的独立文件；这些工作走有界 IPC 异步读取通道，GUI 不写文件。记录线程不等待快照复制或文件 I/O。无定期/退出/崩溃 flush，无常驻日志写入线程；进程退出丢失未导出信息是明确取舍。文件完整关闭才定位，取消/失败清理半成品，不自动上传。IPC stdout 始终只用于协议。

记录连接状态、重试次数/延迟/耗时、设备就绪和失败类别。音频计数复用 mixLoop 的 20ms tick，每 30 秒汇总活动，至多 64 个发送者，计数对象预分配复用；不额外创建音频采样线程。导出时额外读取当前音频原子累计计数，逐发送者计数仍由混音循环独占。原生接收路由按流量触发低频汇总及关闭汇总。无逐帧日志、音频录制、聊天正文、凭据、服务器私钥、认领码或持久身份记录。

日志统计区分路由拒绝、未安装音频处理器、接收队列丢弃、解码失败、抖动缓冲拒绝、静音帧与采集缓冲丢样。它们不是公网丢包率或端到端延迟测量，不能据此声称已修复所有“听不到某人”问题。
