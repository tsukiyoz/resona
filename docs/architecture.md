# 架构设计

日期：2026-09-07。当前实现范围为 M0 和 M1 的连接、无密码频道切换、成员订阅、本地提示音和桌面密码保存；以下明确标注未来组件。

## 产品与部署边界

Resona 首先是本地桌面 GUI 应用。使用 Wails v2 承载 React/TypeScript 界面与 Go 应用服务，正式桌面操作经绑定方法进入 Go，不必经过一个独立 HTTP 控制服务。

根目录保留 Wails 标准入口与资源嵌入，单 Go module 为 `github.com/tsukiyoz/resona`。这是工具链兼容选择，不代表业务代码放在 main 包。未来真正增加机器人/服务端时再决定入口布局和构建方式。

## 当前职责

| 位置 | 职责 | 依赖限制 |
| --- | --- | --- |
| `main.go` / `app.go` | 窗口、生命周期、Go 与 GUI 桥接 | 不实现 TS3 协议 |
| `internal/client` | 本地预览、真实连接生命周期、状态快照、输入校验 | 不导入 Wails、React 或具体协议库 |
| `internal/protocol/ts3` | 持久身份、TS3 连接、本人频道切换、服务器推送的有序归并 | 实现 client.RemoteConnector，不向 GUI 暴露上游类型 |
| `third_party/teamspeak-go` | 固定版本上游快照与最小接收观察接口补丁 | 保留上游模块、MIT 许可与来源说明 |
| `internal` 中的配置存储包 | 书签加载和原子保存 | 不保存密码、身份密钥 |
| `internal/credentials` | macOS 原生钥匙串中的服务器密码 | 实现 client.PasswordStore，不经 GUI 返回密码 |
| `frontend/src` | GUI、视图状态和错误呈现 | 经集中 bridge 调用核心 |
| `frontend` 浏览器适配 | 前端开发预览 | 不声称真实 TS3 接入 |

M0 操作流：界面命令 -> Wails 绑定 -> Go 应用服务 -> 校验 / 存储 / 会话变更 -> Workspace 快照 -> 界面刷新。

所有修改操作返回更新后的快照，使服务端书签和会话状态有一个明确的权威来源。浏览器预览是单独适配器，数据不与桌面共享。

## 数据与会话

- `ServerProfile`：ID、显示名、地址、昵称、`skipPasswordStorage` 偏好。地址校验只代表输入有效，不代表服务器可达或协议兼容。
- `Workspace`：服务器书签、会话、频道、可见成员、消息、最近的通知事件。
- 会话模式：`offline`、`preview`、`connecting`、`connected`、`disconnecting`、`failed`。预览不会伪装成 `connected`。
- 预览仅当前频道包含本人；没有假远端用户、机器人回复或网络延迟。
- 预览消息只保存在进程内存。书签独立保存，退出预览不会删除书签。

连接有 30 秒超时；取消、断开和窗口退出由会话所有者回收资源。每次连接分配 generation，迟到事件不能改写新的会话。首次 `initserver`、`channellistfinished` 和本人所在频道信息到齐才完成连接；频道与成员通过同步观察接口按接收顺序归并。GUI 每秒读取快照，实时语音不经过此轮询。自动重连留待后续。

初始 ready 后适配器在独立任务中发送一次 `channelsubscribeall`，8 秒超时，使用连接生命周期取消。不能在同步协议观察回调中等待命令响应。`Session.memberSyncState` 区分 `pending`、`ready`、`limited`；拒绝或超时写入 `memberSyncError`，不令已建立会话掉线。订阅视图与状态更新不产生加入提示音。GUI 按频道展示同一份可见成员，订阅成功仍受服务器权限限制；不把缺少成员推送解释为确定的空频道。

服务器进入操作统一经过凭据准备与会话服务：双击或 Enter 使用已保存凭据直接连接，否则先打开密码框。`ConnectSavedServer` 与 `ConnectServerWithPassword` 在读取目标凭据、保存偏好之后才断开旧会话，再发起目标连接；准备失败保留原会话。目标地址在准备和实际连接间再次校验，不能把旧地址凭据送到被并发修改的新地址。不提供多会话或切换失败后自动回连。详见 ADR-0008。

本地提示音使用协议适配器产生的瞬时成员事件，应用服务保留最多 64 条带唯一 ID 的通知，随快照返回；短暂加入再离开不会因轮询漏掉。初始化和订阅视图更新静默，服务生命周期在实际转为已连接时产生一次连接成功通知，并负责自身断开通知。GUI 去重并忽略超过 5 秒的通知，通过 Web Audio 播放内置 WAV；成员提示与试听的同类提示间隔至少 400ms，真实连接和断开反馈按事件 ID 去重，不受试听或成员限频影响。连接成功音不受当前频道过滤，但必须仍属于当前已连接会话；异步资源加载后再次检查通知是否仍在当前队列，防止旧会话声音迟到播放。此队列只服务界面通知，不是持久消息总线。详见 ADR-0007。

`SelectChannel` 在远端会话中启动单个异步移动，8 秒超时，`switchingChannelID` 标记待定目标。`channelID` 始终由服务器事件更新。适配器同时等待命令成功响应与本人目标频道状态才完成操作；任意顺序均可。取消会清理本地命令等待与 tracker，不能撤回已发送的命令，所以迟到的真实状态仍要由当前会话处理。断开取消移动，旧会话结果不能影响新会话。密码频道根据 `channel_flag_password` 明确禁用。详见 ADR-0006。

## 配置与错误

配置存于 `os.UserConfigDir()/resona/servers.json`。目录权限 0700、文件权限 0600（以平台实际支持为准）；在同目录写临时文件，再原子重命名。不要在仓库中生成私人配置。

读取失败或 JSON 损坏必须返回错误，保留原文件，不能当作空配置覆盖。表单错误、存储错误、未来网络错误由 GUI 显示；操作失败时保留用户输入。

TS3 身份密钥保存为同目录 `identity.key`，权限 0600，完整临时文件通过不覆盖的原子链接发布；并发创建复用胜出的身份，损坏文件报错且保留。身份方案见 ADR-0005。

桌面服务器密码通过 `github.com/keybase/go-keychain v0.0.1` 调用 macOS 原生 Keychain，使用不云同步的 Generic Password 条目。凭据键为 `SHA-256(bookmarkID + NUL + address)`，值允许为空；是否存在通过独立查询判断。密码不进入 Workspace、书签 JSON、浏览器存储或日志。书签仅保存 `skipPasswordStorage`，其默认值 false 表示默认记住密码。其他平台或没有 cgo 时明确报告密码存储不可用，不退回明文文件。

只有认证成功且会话 generation、书签地址及偏好仍有效时才写入钥匙串。保存失败放入 `Session.credentialError`，保持已连接状态。修改名称或昵称复用条目，修改地址与删除书签清理原条目；独立忘记密码同时关闭该书签的记住偏好。凭据操作与连接生命周期分别串行化，具体存储接口与产品语义见 ADR-0008；该决定更新 ADR-0005 中早期只在连接内存中持有密码的范围。

## 未来协议与音频边界

TS3 协议适配负责身份握手、可靠命令、事件与语音包。客户端应用层负责用户操作和会话状态；GUI 不依赖第三方库的类型。

音频需要独立验证采集、编码、发送、接收、抖动缓冲、解码和播放。不要经 JSON 桥接逐帧搬运实时 PCM；GUI 只传配置和控制命令。Go 管理音频流水线及其 native 依赖。

先围绕真实需求形成最小接口，不提前设计一个包含所有未来协议的庞大通用 Client 接口。频道、权限和错误语义必须以已验证的 TS3 行为为依据。

## 未来扩展与服务端

内置扩展使用事件与命令接口，核心统一持有连接、身份、发送队列与音频设备。外部插件边界另见 ADR-0004。

客户端与服务端可以共享协议编解码和确实一致的值类型，但不共用一个含混的全局状态模型。服务端是会话、频道和权限的权威方；客户端是远端状态的观察者。

服务端仍在同仓库演进，是否拆 Go module 或仓库取决于独立发布和外部引用需求，而不是目录数量。

## 验证策略

- Go：配置保存/重载、非法输入、损坏配置保护、会话命令边界。
- 前端：书签新增编辑删除、预览进出、频道选择、消息、表单和错误状态。
- 桌面：macOS 构建、窗口启动、桥接与真实配置保存。
- 协议：独立真实服务器集成测试，记录双方版本，不能用本地预览替代。
