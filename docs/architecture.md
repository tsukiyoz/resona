# Resona 架构

## 进程与职责

| 位置 | 职责 |
| --- | --- |
| `desktop/` | Rust GPUI 窗口、用户交互、偏好及系统快捷键 |
| `cmd/resona-core` | Go 客户端入口，与桌面通过继承的 NDJSON 管道通信 |
| `internal/client` | 会话、书签、凭据、聊天、语音生命周期与本地状态 |
| `internal/desktopipc` | 请求、事件、资源订阅协调及有界关闭 |
| `internal/protocol/native` | 原生控制命令、状态转换、身份和音频传输适配 |
| `internal/audio` / `native/webrtc-apm` | malgo 设备、SpeexDSP、可选 WebRTC APM 动态库、gopus、抖动缓冲与混音 |
| `internal/nativewire` | Protobuf 控制帧及固定语音头 |
| `internal/noiseudp` | Noise 握手、认证数据报、可靠流、防重放与后台换钥 |
| `cmd/resona-server` / `internal/server` | 权威频道、身份权限、持久化及语音广播 |

客户端与服务端在单仓库演进，客户端核心不依赖 GPUI。音频只在 Go 核心处理；server 解密后转发 Opus，不做编解码或混音。传输为逐跳加密，server 可见明文，不是端到端加密。

## 语音与资源

语音和资源分别承担实时广播与界面观察职责。server 在锁内校验发言权限并取得收件人快照，锁外编码并写入每个收件人的四槽 mutex MPSC 环。满时覆盖最旧待发包，发送前丢弃超过 100ms 的队列项，发送停滞有界退出。仍有共享状态锁，不能据此宣称完全消除锁竞争。

当前频道成员实例、语音 epoch、音质、本人身份和权限持续同步，保护音频路由与命令正确性。首次连接只列出当前频道。客户端按关注范围原子 List+Watch 频道/成员集合，收到递增 revision 的完整范围快照；范围外变化不推送，范围缩小不表示对象已从服务器删除。

前台立即应用资源事件，并每五分钟兜底同步；失去窗口焦点后缩小范围，核心保留最新状态而不逐次刷新 GUI，恢复后一次同步。当前频道必要状态、命令、断线和轻量提示通知保持实时。频道文字仅实时广播，不作为服务端历史资源；客户端显示缓存最多 500 条且正文/昵称/错误合计至多 512 KiB，不按最后一条合并。逐对象 delta、任意 selector 和独立资源索引仍未实现。

## 生命周期与凭据

服务端仅在认证成功加入成员表及会话清理完成时，用 `slog` 记录连接/断开、远端 IP/端口、昵称、成员 ID、会话实例及连接时长。日志在服务器状态锁外写 stderr，不记录密码、身份私钥或消息正文，不进入语音包转发热路径；认证前不记录客户端自报昵称。

连接、频道移动、发送和资源同步使用 session generation 或请求序号隔离迟到完成。普通关闭释放设备和连接，并有 IPC 最终回收边界。意外断线由单 worker 可取消退避重连，认证后先恢复原频道，再发布新会话并重新订阅资源；保持持久身份，麦克风保持静音，不重发未知结果命令。见 ADR-0028。

服务器公钥必须由可信渠道提供。Ed25519 客户端签名绑定 Noise 握手哈希，先验签再加入成员列表。私钥不进入 GUI 或日志。服务器密码按书签 ID、地址、公钥绑定；目标改变不能复用旧凭据，认证成功后才保存。旧书签仅保留管理能力，不支持的格式在凭据读取和网络连接前拒绝。

## 桌面状态

音频配置按固定顺序分别定义发送 `preprocess`（AEC、ANS）和每成员接收 `postprocess`（AGC），每项选择关闭、SpeexDSP 或 WebRTC APM。后者是同仓库原生 Rust `cdylib`，以有版本号的 C ABI 供 Go cgo 按需动态加载，不通过桌面 IPC 传递 PCM；WebRTC 的 10ms 输入在库内由 20ms 帧拆成两段。新安装默认仅启用 SpeexDSP 接收 AGC，发送链默认全关，旧偏好明确关闭时不覆盖；未选 WebRTC 时不加载库。Core 能力响应提供实际可用后端的阶段、处理项、ID、名称和说明，选择时核验 ABI/加载/创建，错误保留旧链。发送链由编码 worker 独占，控制端先准备候选对象，再经控制通道在帧边界交换并由原 worker 销毁旧链。接收 AGC 位于 Opus 单声道解码后、个人增益/全局增益混音前；状态由混音 worker 独占，按成员实例隔离并在短暂停顿间保留，最多 64 项/空闲 30 秒。音乐、提示音、麦克风试听绕过接收链；未开启时不创建处理器。Core 返回操作序号和连接代次供 GUI 事件/查询确认，无逐帧 IPC、每用户线程或额外定时器。

详情从工作区事件投影，不单独轮询。频道音质为 20/32/48 kbps 预设或 16–64 kbps 自定义，编码线程在帧边界应用。个人收听音量缓存按会话和成员实例隔离，最多 128 项，临时缩小订阅不会丢失设置。全局与个人收听增益在混音时相乘，GUI 用 dB 表示，全局默认约 +6 dB；快捷增益命令只发布配置，成功后持久化。混音峰值限幅不添加音频缓冲。聊天只保留当前频道本次进入后的记录，成功换频道、主动离服及重连成功清空，草稿仍按原范围隔离。

设置面板持有基线和草稿，只合并修改字段。在线音频应用沿用 ConfigureVoice 异步设备生命周期，优先通过语音事件确认；命令受理后立即查询一次，若仍在处理中，仅本次应用期间每秒兜底查询，最多 20 秒。操作序号、连接代次、配置匹配且无错误才保存；超时显示结果尚未确认并保留草稿。离线 SetVoicePreferences 不打开设备。应用期间拒绝重复操作，连接改变或 IPC 失败中止本次确认。仅通知/快捷键偏好改变不触发音频重配；平时没有音频设置轮询或闲置计时器。

成员提示由连续收到的当前频道成员状态生成。首次同步、自己换频道、普通资料修改和订阅范围变化静默；真实加入和离开分别生成瞬时事件，再进入有界通知队列。GUI 去重并过滤过期事件，后台保持轻量声音通道。

运行日志统一 `slog`；客户端使用预分配的结构化内存环（最多 512 条、最近 15 分钟），仅用户导出时异步生成 JSON 文件。记录竞争时丢弃并计数，不等待导出，不增加闲置计时器或写盘线程；退出不刷新。服务端使用 stderr。CLI 结果和 IPC stdout 保持独立。诊断只接受审核过的事件和原始类型字段，不记录密码、私钥、认领码、音频、聊天正文或任意 error 对象。
