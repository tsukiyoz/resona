# Resona 架构

## 进程与职责

| 位置 | 职责 |
| --- | --- |
| `desktop/` | Rust GPUI 窗口、用户交互、偏好及系统快捷键 |
| `client/` | UI 无关 Rust 核心：会话/重连、资源、书签/凭据、聊天、音频、诊断与签名更新 |
| `client/src/audio` / `native/client-audio` | 设备回调环、Opus、抖动/混音、帧边界 DSP 与提示音 |
| `native/webrtc-apm` | 可选 WebRTC/RNNoise C ABI 动态库，与客户端同进程 |
| `internal/client` / `internal/protocol/native` / `internal/audio` | 机器人、服务器互通与基准的 Go 参考实现，不进入桌面包 |
| `internal/updates` | Go 发布工具的签名清单与发布包身份校验 |
| `internal/nativewire` | Protobuf 控制帧及固定语音头 |
| `internal/noiseudp` | Noise 握手、认证数据报、可靠流、防重放与后台换钥 |
| `cmd/resona-server` / `internal/server` | 权威频道、身份权限、持久化及语音广播 |

客户端与服务端在单仓库演进，Rust 客户端核心不依赖 GPUI。server 解密后转发 Opus，不做编解码或混音。传输为逐跳加密，server 可见明文，不是端到端加密。

2026-10-21 按 ADR-0032 切换至进程内 `client/` Rust library，GPUI 经有界异步
命令/事件通道调用。普通请求与安全取消分开受理，入队意图代次防止迟到按下/连接；
展示字段独立合并、公平送达。网络拥有单个 Tokio runtime，音频专用线程拥有设备、
编解码、处理器和混音；回调只交换有界 PCM 并唤醒 owner。Go 产品入口和 NDJSON
IPC 已移除，Go server、测试/基准参考及内嵌 JetStream 保留。生产聊天目录仍显式为
access-dir/chat。迁移不等于已获得内存或游戏性能收益，仍须等负载测量。

更新仅由设置中的关于页启动独立有界检查，通过进程内事件回显；没有启动联网或
空闲轮询。Core 解释 `resona-package.json` 的 distribution，GUI 只按能力渲染。
当前 Windows ZIP 和 macOS .app 均为 portable：验证签名清单后只打开对应版本
发布页，用户手动下载替换，不下载包、不写缓存、不交接退出。安装器升级尚未
接通，不暴露安装能力；旧 ZIP 目录替换器已移除。配置仍位于产品目录外。
更新不走语音处理或服务端协议。见 ADR-0030 和 updates.md。

## 语音与资源

语音和资源分别承担实时广播与界面观察职责。server 在锁内校验发言权限并取得收件人快照，锁外编码并写入每个收件人的四槽 mutex MPSC 环。满时覆盖最旧待发包，发送前丢弃超过 100ms 的队列项，发送停滞有界退出。仍有共享状态锁，不能据此宣称完全消除锁竞争。

当前频道成员实例、语音 epoch、音质、本人身份和权限持续同步，保护音频路由与命令正确性。首次连接只列出当前频道。客户端按关注范围原子 List+Watch 频道/成员集合，收到递增 revision 的完整范围快照；范围外变化不推送，范围缩小不表示对象已从服务器删除。

前台立即应用资源事件，并每五分钟兜底同步；失去窗口焦点后缩小范围，核心保留最新状态而不逐次刷新 GUI。有缓存时恢复前台异步静默刷新；初次同步或失败后的手动重试显示工作区上方紧凑提示，使用透明 hit-test 层阻挡工作区交互，不整体染色，语音工具栏和退出保持可用。每轮最多三次 2 秒请求，300/600ms 退避；失败后阻止频道交互并等待手动重试，停止兜底定时器。单协调 worker 取消并合并关注变化，旧 job 结束后才开始新 job；事件匹配会话和观察代次，不能跨会话覆盖状态。资源失败不等于连接失败；会话、对象和权限校验仍生效，命令由服务端授权。当前频道必要状态、命令、断线和轻量提示通知保持实时。逐对象 delta、任意 selector 和独立资源索引仍未实现。

频道文字使用 server 内嵌 JetStream 文件流，默认每频道 200 条、全局逻辑 64 MiB、
最长 7 天；无对外 NATS 端口、无客户端 NATS 依赖。保存确认和历史读取在语音成员锁外，
每成员一个可取消的临时 consumer 连续提供当前频道历史与实时消息。稳定序号、时间、
作者身份和客户端 ID 支持排序/去重，频道 epoch 隔离旧数据。加载状态独立于资源与
语音，失败可重试，不因聊天回复超时关闭语音。客户端显示缓存仍最多 500 条 / 512 KiB，
启动期间增量也有界，历史不产生未读提示。文件逻辑限制不等于物理磁盘配额；新依赖和
文件存储会增加服务端运行开销，长期容量和等负载性能待验证。见 ADR-0031。

管理资源复用同一个内置 broker 的 `RESONA_RESOURCES` KV：频道与 ID 分配器、
owner、认领码摘要/到期时间在一个有界文档内 CAS 提交，不设置 TTL。一个共享
watch 接收初始状态和后续修订，再按连接兴趣投影；不增加每用户 KV 消费者。
权限读取只看内存，持久化不持有语音路由锁。旧 JSON 仅新桶初始化时严格导入，
后续 KV 为唯一事实来源；非法状态/观察失败停止服务。Cobra 提供分层 CLI，
HTTP 管理延后，未来入口须复用业务授权与校验。详见 ADR-0033 和 server.md。

频道 v2 记录独立保存默认频道 ID，数组只决定显示顺序。管理员改序用 ID 锚点
而非客户端旧索引，在同一 CAS 内移动数组元素；默认入口、ID 分配、音频路由与
成员 epoch 均不变。完整兴趣的客户端复用资源事件收到顺序，后台当前频道视图
不因无关改序收到额外快照。桌面拖放和右键移动共享异步命令，不乐观覆盖权威列表。

## 生命周期与凭据

服务端仅在认证成功加入成员表及会话清理完成时，用 `slog` 记录连接/断开、远端 IP/端口、昵称、成员 ID、会话实例及连接时长。日志在服务器状态锁外写 stderr，不记录密码、身份私钥或消息正文，不进入语音包转发热路径；认证前不记录客户端自报昵称。

连接、频道移动、发送和资源同步使用 session generation 或请求序号隔离迟到完成。首次连接临时错误最多三次尝试，明确拒绝立即失败；失败页提供手动处理。普通关闭停止采集、取消网络并等待有界清理，再通知 UI 退出；系统设备/授权调用不可强制中断，迟到完成不能恢复状态，最终进程退出不无限等待线程。意外断线由单 worker 可取消退避重连，三次失败后显式提示并继续慢速恢复；立即重试只唤醒等待，不并发拨号。认证后先恢复原频道，再发布新会话并重新订阅资源；保持持久身份，麦克风保持静音，不重发未知结果命令。见 ADR-0028。

服务器公钥必须由可信渠道提供。Ed25519 客户端签名绑定 Noise 握手哈希，先验签再加入成员列表。私钥不进入 GUI 或日志。服务器密码按书签 ID、地址、公钥绑定；目标改变不能复用旧凭据，认证成功后才保存。旧书签仅保留管理能力，不支持的格式在凭据读取和网络连接前拒绝。

## 桌面状态

2026-10-21：发送 ANS 增加上游 RNNoise regular 可选实现，保留 Speex 默认和
已保存选择。与 WebRTC 共用已有原生音频动态库，C ABI 2 的 kind 4 按两个 10ms
子帧处理；控制端准备、编码 worker 独占替换/销毁，不新增线程、PCM IPC 或后台
下载。Core 按实际 ABI 提供选项及悬停说明；旧 ABI 1 不展示 RNNoise。
源码/model 固定版本与集成证据见 native/rnnoise/README.md。

本地偏好和书签使用独立的 `schema_version`（当前 1），无版本旧文件只在内存迁移，
首次保存前备份原始字节。无法读取的偏好使用静音进入、3A 全关的只读恢复配置，
界面提示并跳过退出保存；书签读取失败仍阻止 Core 启动。保存重新校验现存文件，
拒绝损坏、未来版本和当前版本未知字段。见 ADR-0029；不提供跨进程配置写入事务。

2026-09-18 默认值覆盖：新配置采用发送 SpeexDSP AEC/ANS 与接收 WebRTC AGC2，已有处理链不覆盖。主动连接后的首次语音初始化按 AutoUnmuteOnConnect 偏好（默认开启）决定采集；切频道不覆盖当前静音，自动重连仍静音。该偏好随配置传递，只在首次初始化使用，不进入逐帧处理。下段早期默认开启项描述由本条取代，具体审查见 audio-processing-review.md。

音频配置按固定顺序定义发送 `preprocess`（AEC、ANS）和每成员接收 `postprocess`（AGC），独立选择关闭、SpeexDSP、WebRTC，ANS 另有 RNNoise。新配置默认 SpeexDSP AEC/ANS 和 WebRTC AGC2，已保存配置不覆盖。Core 按实际 ABI 提供菜单及说明，不能用静默回退掩盖缺失后端。单个音频 owner 线程在帧边界验证和替换候选链，失败保留旧链，旧对象在该线程销毁；WebRTC 的 20ms 帧在动态库内部拆成两个 10ms 帧。接收 AGC 位于 Opus 解码后、个人/全局增益和混音前，按成员实例隔离，最多 64 项、空闲 30 秒回收。提示音和本地试听绕过接收链；未选择的后端不常驻创建。操作序号、代次和范围检查用于 GUI 确认及迟到隔离，没有逐帧 UI 消息或每用户线程。

详情从工作区事件投影，不单独轮询。频道音质为 20/32/48 kbps 预设或 16–64 kbps 自定义，编码线程在帧边界应用。个人收听音量缓存按会话和成员实例隔离，最多 128 项，临时缩小订阅不会丢失设置。全局与个人收听增益在混音时相乘，GUI 用 dB 表示，全局默认约 +6 dB；快捷增益命令只发布配置，成功后持久化。混音峰值限幅不添加音频缓冲。聊天视图在成功换频道、主动离服及重连成功时清空，进入目标频道后恢复有限历史，草稿仍按原范围隔离。

设置面板持有基线和草稿，只合并修改字段。在线音频应用沿用 ConfigureVoice 异步设备生命周期，优先通过语音事件确认；命令受理后立即查询一次，若仍在处理中，仅本次应用期间每秒兜底查询，最多 20 秒。操作序号、连接代次、配置匹配且无错误才保存；超时显示结果尚未确认并保留草稿。离线 SetVoicePreferences 不打开设备。应用期间拒绝重复操作，连接改变或核心失败中止本次确认。仅通知/快捷键偏好改变不触发音频重配；平时没有音频设置轮询或闲置计时器。

成员提示由连续收到的当前频道成员状态生成。首次同步、自己换频道、普通资料修改和订阅范围变化静默；真实加入和离开分别生成瞬时事件，再进入有界通知队列。GUI 去重并过滤过期事件，后台保持轻量声音通道。

Go 服务端运行日志使用 `slog` 写 stderr；Rust 客户端使用预分配的结构化内存环（最多 512 条、最近 15 分钟），仅用户导出时异步生成 JSON 文件。记录竞争时丢弃并计数，不等待导出，不增加闲置计时器或写盘线程；退出不刷新。CLI 结果与诊断保持独立。诊断只接受审核过的事件和原始类型字段，不记录密码、私钥、认领码、音频、聊天正文或任意 error 对象。
