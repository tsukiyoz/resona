# 桌面唤醒与后台性能测量

必须区分活跃窗口、可见但失焦、真正最小化三个状态。失去焦点时减少资源同步，不等于操作系统已停止显示时钟。

固定 GPUI 版本的 macOS 显示时钟随窗口可见性启停；时钟回调只在 dirty/force_render 或 needs_present 时绘制/提交，因此唤醒频率不是实际 FPS 或 GPU 使用率。

## 测量约定

1. 使用 release 构建，记录提交、dirty 状态、设备、网络、人数和音频配置。
2. 采集桌面及全部核心子进程，区分内存口径、单核 CPU 百分比和 I/O。
3. 最小化后不要调用 UI/AX/截图工具，这些操作可能恢复窗口并污染测量。使用独立进程采样器。
4. 预热后采样，至少重复多个独立启动；记录采样期间的网络/音频/游戏负载。
5. Windows 实测游戏帧时间和 GPU，macOS 结果不能代替 Windows。

macOS 的进程唤醒计数不是电脑从睡眠醒来的次数。短窗口接近零的 CPU 读数不适合推广为续航或长期倍数结论。

工具与 CSV 分析见 [desktop-perf](../tools/desktop-perf/README.md)。当前开发版尚未完成本轮游戏负载测量，不引用旧版本比较作为性能结论。
