## 文档约定

- 已实现、计划、待验证必须明确区分。
- ADR 记录背景、决定、代价和重新评估条件；改变决定时新增 ADR，不抹去历史。
- 兼容性结论注明服务端版本、客户端版本、平台和复现步骤。
- 不把预览 UI、mock 或仅通过单元测试的代码视为真实语音接入完成。
- 服务端独立设里程碑，不因客户端协议库可用就推断服务端可直接实现。
