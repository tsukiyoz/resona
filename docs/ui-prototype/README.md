# Retired UI prototypes

The initial, Ant Design light/dark and MineRadio comparison prototypes were
retired on 2026-09-14 after their design work moved into the GPUI desktop.
Their React/CSS sources, generated HTML and standalone npm build are no longer
maintained. Earlier revisions remain available in Git history.

The product GUI is `desktop/`. See [product behavior](../product.md) and
[ADR-0016](../adr/0016-gpui-desktop-ui-and-wails-retirement.md) for the accepted
interaction and maintenance boundaries. Historical prototype entries in those
documents record past decisions, not currently available preview pages.

New prototypes can be introduced here for a concrete future design question;
they are not dependencies of the application or its build.
