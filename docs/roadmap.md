# 推进计划

当前方向：独立 Noise UDP 客户端与服务端，GPUI 为唯一产品 GUI；单仓库开发，暂不公开稳定 SDK。

## 当前已有

- 2026-10-21：发送 ANS 接入 RNNoise regular，与 SpeexDSP/现有 WebRTC NS 可选；
  算法菜单项和当前选项提供 Core 描述悬停提示，保留现有默认值及异步应用流程。
  本机 Core 全量/相关 race、原生库、桌面单测通过；Windows 产品包和游戏负载待验收。

- 原生加密连接、持久客户端身份、所有者认领及认领码刷新。
- 频道创建、编辑、空频道删除、持久化与服务端授权。
- 多人 Opus 转发、静音/收听、单人音量、输入增益、三种发言方式、音频处理、在线本地试听。
- 频道文字通过嵌入式 JetStream 保留近期历史，默认每频道 200 条、全局 64 MiB、7 天；客户端有界显示缓存。条数/大小/过期、重启与隔离本地回归通过；长期磁盘、Windows 实机和等负载性能待验收。见 ADR-0031。
- 按关注范围 List+Watch、后台资源合并、前台恢复同步和五分钟兜底。
- 当前功能分支：连接与资源同步分离，三次短重试、显式失败及取消；正常资源刷新
  静默，资源失败等待手动重试，断线失败后保留慢速恢复。Go/race 与桌面测试、
  macOS 打包通过；遮罩实窗及 Windows 验收未完成，见 verification.md。
- 语音优先工作区、底部可折叠和拖高的频道文字面板，固定尺寸发送箭头置于输入框右下角；设置草稿经应用后生效。
- v0.1.0 收敛为单一传输，补原生成员进出提示。验收范围与待验证项目见 verification.md。
- 可取消自动重连和内存诊断导出，麦克风静音恢复；本地服务重启、导出实窗和竞态回归通过，Windows 实机待验证。

## 下一步

- 当前优先推进客户端 Rust 迁移（ADR-0032）：先完成与 Go server 实际互通的
  Noise/Protobuf/身份基础，再迁移会话/配置/凭据与音频设备链，最后接入 GPUI、
  删除 Go Core/桌面 IPC 并测量全进程性能。现有产品保持完整可用；server 和
  内嵌 JetStream 不随客户端重写。各阶段验收记录后再标记完成。

当前按顺序推进：

- 本地偏好与书签格式版本、迁移备份及异常写入保护（当前功能分支，验证记录见 verification.md）。
- 更新按分发类型区分（ADR-0030）：本分支的 portable 包只手动检查签名清单，
  打开源仓库对应版本发布页；设置内更新入口、包元数据和发布工作流已实现，
  实机及首次 tag 发布待验收。旧便携 ZIP 自动替换器已移除。
  安装包、安装器负责的应用内升级/恢复/重启和 macOS Developer ID/公证仍待推进。
- Windows 可靠性与游戏性能实机验收，再按测量结果处理音频边界及 UI 模块拆分。
- 排查 macOS 原生自动化激活窗口时的 GPUI 重入锁阻塞，复测聊天悬停复制；本轮采样与未完成验收见 verification.md。
- REA 仅作为之后有明确问题的本地音频行为调查候选，不恢复旧协议兼容；尚未集成或运行。

1. 重连实机验收：Windows 休眠恢复、网络切换、游戏焦点和蓝牙设备；验证诊断日志能定位真实听音故障。
2. 简化管理员：角色委派、踢出/封禁及服务端校验，客户端入口按授权显示。
3. 网络质量：丢包、队列丢弃、RTT 和转发延迟观测；先测量再引入语音拥塞适应。
4. Windows 四人长听测、游戏焦点 PTT、设备热插拔、最小化恢复及全进程 CPU/GPU 性能。
5. 移动端准备：明确音频设备、权限、后台生命周期和核心嵌入接口，再验证 Android/iOS 小样。
6. 客户端 3A：`test/audio3a` Windows/Linux 独立测量已通过。功能分支实现发送 AEC/ANS 与每用户接收 AGC 的固定顺序处理链、SpeexDSP 和可选 WebRTC AEC3/NS/AGC2、Core 操作回执与编码 worker 帧边界替换；本机静态库与实际 Go 加载测试已通过。2026-10-20 补固定真人语音/噪声 manifest、参考指标、匿名音量匹配试听和 RNNoise regular/little 筛选（见 test/audio3a/README.md）；首轮为短英语加合成粉红噪声，第二轮为四位中文说话人加录制键盘/空调/交谈及调幅压力场景，本机完成 300 行计时与统一匿名包，已收集维护者定性反馈：RNNoise 两模型键盘抑制有效，背景交谈时 regular 人声较自然但仍有失真；little 优先验证，regular 保留质量可选候选。另已完成 ANS→产品 gopus→独立接收 AGC2 的 180 行本地测量和三阶段试听包，little 完整链折算单核约 3.48%，但尖峰、增益适应和听感仍须验收。尚需新版 Windows/Linux CI、实机设备链、真实游戏录音听感、内存和游戏负载验证，再决定神经降噪产品接入；接收新成员处理器的异步预热仍待评估。实验不直接决定默认开启项。

按需求再考虑对象级资源 delta、频道访问控制、音乐立体声和扩展 SDK。子频道、HTTP 管理后台、集群与自定义插件体系均不提前扩张。
