# 推进计划

当前方向：独立 Noise UDP 客户端与服务端，GPUI 为唯一产品 GUI；单仓库开发，暂不公开稳定 SDK。

## 当前已有

- 原生加密连接、持久客户端身份、所有者认领及认领码刷新。
- 频道创建、编辑、空频道删除、持久化与服务端授权。
- 多人 Opus 转发、静音/收听、单人音量、输入增益、三种发言方式、音频处理、在线本地试听。
- 频道实时文字及客户端有界显示缓存，配置系统密码存储。
- 按关注范围 List+Watch、后台资源合并、前台恢复同步和五分钟兜底。
- 语音优先工作区、底部可折叠和拖高的频道文字面板，固定尺寸发送箭头置于输入框右下角；设置草稿经应用后生效。
- v0.1.0 收敛为单一传输，补原生成员进出提示。验收范围与待验证项目见 verification.md。
- 开发分支新增可取消自动重连和内存诊断导出，麦克风静音恢复；本地服务重启、导出实窗和竞态回归通过，Windows 实机待验证。

## 下一步

1. 重连实机验收：Windows 休眠恢复、网络切换、游戏焦点和蓝牙设备；验证诊断日志能定位真实听音故障。
2. 简化管理员：角色委派、踢出/封禁及服务端校验，客户端入口按授权显示。
3. 网络质量：丢包、队列丢弃、RTT 和转发延迟观测；先测量再引入语音拥塞适应。
4. Windows 四人长听测、游戏焦点 PTT、设备热插拔、最小化恢复及全进程 CPU/GPU 性能。
5. 移动端准备：明确音频设备、权限、后台生命周期和核心嵌入接口，再验证 Android/iOS 小样。

按需求再考虑对象级资源 delta、频道访问控制、音乐立体声、持久聊天和扩展 SDK。子频道、HTTP 管理后台、集群与自定义插件体系均不提前扩张。
